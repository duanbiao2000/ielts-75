# 雅思口语场景库 · 规划方案

> 定位：在 16 个话题文件夹（解决"考什么"）之外，补充 **场景库**（解决"说什么、怎么说"）。
> 每个场景提供可直接采纳使用的表达与对话，覆盖考试、生活、职场、出行、留学、旅行、社交七大领域。

## 一、场景库设计

- 目录：`ielts-75/materials/scenarios/`，按七大领域分 7 个子目录
- **一个场景 = 一个文件夹**，固定 3 个文件：

| 文件 | 内容 |
| --- | --- |
| `README.md` | 场景定位、何时用到、学习重点、与 11 课/话题库的关联 |
| `01-核心表达.md` | 场景高频词、"开口就说"基础句型、进阶表达、易错提醒 |
| `02-情景对话与练习.md` | 2 段实战对话（中英对照，标注可替换表达）+ 角色扮演与自测任务 |

- 表达难度对齐雅思 7.5：自然、地道、有变化，不堆生僻词
- 所有表达可迁移：同一场景的句型可复用于口语考试各部分与真实生活

## 三、使用方式

1. **日常积累**：按领域选场景，先读核心表达，再角色扮演对话；
2. **考试对接**：考场应答、面试、学术沟通等场景直接迁移到口语考试各部分；
3. **录音自测**：每个场景的对话脱稿录音，回听检查流畅度与发音；
4. **与话题库配合**：场景句型可填充到话题库（如"面试"句型用于"工作与职业"话题卡）。
