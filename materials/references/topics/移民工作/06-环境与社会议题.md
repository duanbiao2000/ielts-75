# 参考卡片：环境与社会议题（移民工作·06）

> 对应：`materials/移民工作/06-环境与社会议题/`
> 适用：学有余力者的可选深读，主题为环境、气候与社会议题。

## 一、精选资源

### 【必看】
1. **The Guardian · Environment 栏目**（新闻媒体）
   - ROI 理由：环境议题讨论充分、表达地道，
     与雅思环境类话题高度重合，观点与词汇兼备。
2. **BBC 6 Minute English**（环境相关单集，如 climate, recycling）
   - ROI 理由：环境话题的浅显入口，适合精听 + 跟读。

### 【推荐】
3. **NASA Climate / 国家地理环境专题**（权威机构/媒体）
   - 事实与数据支撑，让环境观点更有说服力。
4. **The Conversation · Environment 频道**（学术新闻站）
   - 环境议题的深度视角，为 Part 3 提供论证。

### 【挑战】
5. **IPCC 气候报告（科普解读版）**（报告/论文）
   - 环境议题的权威深度来源，冲高分时积累宏观观点。
6. **An Inconvenient Truth（难以忽视的真相，纪录片，维基百科有词条）**（纪录片）
   - 环境议题的经典影像资料，精听 + 观点积累。

## 二、看什么

- 环境类高频词：climate change, sustainability, environmentally friendly, carbon footprint；
- 数据与趋势表达：emissions have risen / fallen by…；
- 环境议题的利弊与责任论证（呼应模块 08）。

## 三、深入任务

1. 读一篇 The Guardian 环境报道，摘录 3 个数据表达句型；
2. 看 An Inconvenient Truth 片段，做精听，摘录 3 个观点句；
3. 回答："Who should be responsible for protecting the environment?"，
   用分层论证（个人/政府/企业），录音回听。

## 四、与本项目的关联

Part 3 环境类问题可直接调用本卡论点与数据表达。
