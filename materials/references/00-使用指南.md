# 参考资料库使用指南（00）

> 定位：为整个项目提供**高 ROI 外部参考资料**，供学有余力的同学深入具体细节。
> 与 11 课（方法论）、16 话题库、24 场景库、10 模块的关系：
> **前者是"主线训练"，本库是"可选深读"——不替代主线，只做加法。**

## 一、目录结构

```
materials/references/
├── 00-使用指南.md            # 本文件
├── topics/                   # 16 张话题参考卡（与 materials/ 话题一一对应）
│   ├── 留学/  移民工作/  通用/
├── scenarios/                # 24 张场景参考卡（与 scenarios/ 场景一一对应）
│   ├── 考试/ 生活/ 职场/ 出行/ 留学/ 旅行/ 社交/
└── modules/                  # 12 张模块参考卡（与 modules/ 模块一一对应）
```

每张参考卡对应一个话题/场景/模块，可独立浏览，也可从各文件夹 README
末尾的"进一步深读"入口进入。

## 二、三层分级体系

每张卡片内的资源按 ROI 分三层，按需取用：

| 层级 | 含义 | 投入建议 |
| --- | --- | --- |
| **必看** | 直接对应考点或核心方法，投入产出比最高 | 优先看，每层至少 1 项 |
| **推荐** | 拓宽语感与见识，积累可迁移表达 | 时间富余时看 |
| **挑战** | 论文、深度长文、学术向内容 | 学有余力、想冲高分时看 |

## 三、参考卡片的统一结构

1. **精选资源**：分层列出，标注类型（书影音词条 / 播客 / 博客 / 论文 / 网站）；
2. **看什么**：观看/阅读时抓取的具体目标（词汇、句型、论证、语音等）；
3. **深入任务**：给学有余力者的可操作任务，把外部输入转成口语输出；
4. **与本项目的关联**：指明对应话题/场景/模块，方便回练。

## 四、使用纪律（重要）

1. **主线优先**：深读是加餐，不是正餐。先完成当天的输出训练（话题/场景/模考），
   再按需深读；
2. **带着任务看**：每张卡都给了"看什么"，看之前明确目标，避免无目的浏览；
3. **输入必须转输出**：看完后完成"深入任务"，把学到的表达用进自己的回答，
   否则只是看过，不会变成能力；
4. **不求全看**：三层资源选一层即可，不必每张卡都全看，避免贪多；
5. **以输出验证**：学到的表达，在下次模考或录音自答中使用，验证是否内化。

## 五、与模块 06（输入）的联动

- 模块 06 的精听/泛听/跟读需要素材，本库的"必看"资源就是现成素材来源；
- 看/听完一段材料后，按卡片里的"深入任务"做跟读、复述或观点输出，
  形成"输入 → 输出"闭环。
