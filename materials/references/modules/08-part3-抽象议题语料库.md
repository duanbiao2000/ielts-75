# 参考卡片：Part 3 抽象议题语料库（模块 08）

> 对应：`modules/08-part3-抽象议题语料库/`
> 适用：学有余力者的可选深读，主题为抽象议题的深度语料。

## 一、精选资源

### 【必看】
1. **The Conversation（学术新闻站）**（网站）
   - ROI 理由：学者撰写的议题讨论，观点规范、论证清晰，
     是 Part 3 抽象议题的最佳语料来源，与模块 08 直接对应。
2. **TED · 社会/科技议题演讲**（演讲，带字幕）
   - ROI 理由：议题类观点的范本，学习如何有层次地论证。

### 【推荐】
3. **The Economist / The Guardian 评论**（新闻媒体）
   - ROI 理由：高质量议题评论，积累观点句与论证方式。
4. **BBC 6 Minute English**（议题相关单集）
   - ROI 理由：议题的浅显入口，先建立概念再深入。

### 【挑战】
5. **权威报告与论文（如 NASA 气候、IPCC 报告、学术综述）**（报告/论文）
   - ROI 理由：宏观议题的权威深度来源，冲高分时积累宏观观点。

## 二、看什么

- 观点句、理由句、让步句的多样表达；
- 论证的层次：观点 → 解释 → 举例 → 让步；
- 议题类词汇与搭配。

## 三、深入任务

1. 从 The Conversation 选 2 个议题，各摘录 3 个观点句进 Anki；
2. 看一段 TED 议题演讲，分析其论证结构并仿写；
3. 用新语料独立回答 3 个 Part 3 问题，录音回听。

## 四、与本项目的关联

直接服务于模块 08；议题语料同时丰富话题库各话题的 Part 3 论证，
是 Part 3 上 7.5 的关键语料库。
