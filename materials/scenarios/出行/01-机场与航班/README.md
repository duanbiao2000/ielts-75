# 场景：机场与航班

## 场景定位

值机、安检、登机、航班服务、延误与改签——出行最高频场景，
雅思听力 Section 1 常考，口语中可迁移到旅行话题。

## 何时用到

- 机场办理手续、询问航班信息；
- 航班延误、改签、行李问题；
- 机上服务沟通。

## 学习重点

1. **值机与问询**：标准流程表达；
2. **问题处理**：延误、改签、行李的沟通；
3. **数字与时间表达**：航班号、时间、日期的准确表达。

- 听力 Section 1 机场场景词汇互通，配合第 2 课语音训练。
