# 场景：酒店入住与退房

## 场景定位

酒店预订、入住登记、房间问题、退房结算——旅行住宿核心场景，
雅思听力与口语的高频考点。

## 何时用到

- 预订、入住、换房；
- 房间设施问题、额外服务请求；
- 退房、结账、寄存行李。

## 学习重点

1. **入住流程**：预订确认、登记、询问设施；
2. **房间问题**：设施故障、噪音、换房；
3. **退房结算**：账单、延迟退房、行李寄存。

## 与现有资源的关联

- 词汇对接话题库「出行与旅行」「地点与空间」；
- 配合第 2 课连读弱读，听酒店场景对话更轻松。
