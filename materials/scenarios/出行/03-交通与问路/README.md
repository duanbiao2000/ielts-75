# 场景：交通与问路

## 场景定位

日常出行、公共交通、问路指路——生活与旅行高频场景，
雅思听力 Section 1/2 常考（地图题、交通场景）。

## 何时用到

- 问路、指路、确认方向；
- 乘坐公交、地铁、出租车；
- 讨论出行方式与路线。

## 学习重点

1. **问路与指路**：方位词与方向表达；
2. **公共交通**：购票、换乘、询问班次；
3. **出行选择**：比较不同交通方式。

## 与现有资源的关联

- 配合第 2 课连读弱读，听交通场景更轻松。
