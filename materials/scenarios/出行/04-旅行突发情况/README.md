# 场景：旅行突发情况

## 场景定位

旅行中遇到问题时的沟通：迷路、财物丢失、生病、行程变更、求助。
考察"问题描述 + 求助 + 应对"的完整表达，是旅行安全与口语实战的重要能力。

## 何时用到

- 旅行中迷路、错过车次、物品丢失；
- 身体不适需要求助；
- 向酒店、警方、工作人员寻求帮助。

## 学习重点

1. **描述问题**：清晰陈述发生了什么；
2. **请求帮助**：礼貌求助、说明需求；
3. **应对与缓解**：表达冷静、寻求解决方案。
