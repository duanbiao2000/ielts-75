# 场景：行程规划与预订

## 场景定位

旅行前规划行程、预订交通住宿、咨询行程信息——旅行第一步，
口语中可迁移到"旅行经历"话题，听力常考预订场景。

## 何时用到

- 规划行程、咨询路线与景点；
- 预订机票、酒店、门票；
- 调整与确认预订信息。

## 学习重点

1. **咨询与规划**：询问景点、路线、时间；
2. **预订沟通**：确认信息、价格、时间；
3. **变更与确认**：修改、确认预订细节。

## 与现有资源的关联

- 词汇对接话题库「出行与旅行」「地点与空间」；
- 预订表达与出行类场景（机场、酒店）互通。
