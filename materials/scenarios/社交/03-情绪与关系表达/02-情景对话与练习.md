# 情绪与关系表达 · 情景对话与练习

> 【】内为可替换表达。

## 对话一：感谢与回应

**You**: **【Thank you so much for helping me with the project — it made a big difference. / I really appreciate your help with the project — it really helped.】**

**Friend**: **【You're welcome — I'm glad I could help. / No problem at all — happy to help.】**

**You**: **【I can't thank you enough. / I'm really grateful.】** **【If you ever need anything, just let me know. / If you ever need anything, I'm here.】**

**Friend**: **【Thanks, I appreciate that. / Thanks, that's kind.】**

## 对话二：道歉与接受

**You**: **【I'm sorry about being late — it was completely my mistake. / I'm really sorry I was late — that was my mistake.】** **【I feel terrible about it. / I feel bad about it.】**

**Friend**: **【No worries — it happens. / Don't worry about it, it's okay.】**

**You**: **【Thanks for being so understanding. / Thanks for understanding.】** **【It won't happen again. / I'll make sure it doesn't happen again.】**

## 对话三：建议与安慰

**Friend**: **【I've been feeling really stressed about the exam. / I've been really stressed about the exam.】**

**You**: **【I'm sorry to hear that — that sounds tough. / I'm sorry to hear that — it sounds tough.】** **【Have you thought about making a study plan? / What about setting up a study plan?】** **【It might help to break it down into smaller steps. / You could try breaking it into smaller steps.】**

**Friend**: **【That's a good idea — maybe I'll try that. / That sounds good, I'll try that.】**

**You**: **【You'll get through it — everything will work out. / You'll manage — things will get better.】** **【I'm here if you want to talk. / I'm here if you need to talk.】**

## 练习任务

1. **角色扮演**：两人一组，完成感谢、道歉、建议安慰三段对话，角色互换；
2. **脱稿录音**：单人完成三段对话，注意不同情感表达的语气；
3. **自测清单**：
   - 感谢、道歉是否具体且有分寸？
   - 拒绝时是否先表意愿、再说明原因？
   - 建议是否委婉、尊重（Have you thought about…）？
4. **迁移练习**：把情感表达与话题库「人物与关系」「经历与故事」结合，
   录一段"描述一个对你影响深刻的人"的回答，融入感谢/感受表达。
