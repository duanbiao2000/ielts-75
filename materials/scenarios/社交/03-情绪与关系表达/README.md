# 场景：情绪与关系表达

## 场景定位

感谢、道歉、拒绝、建议、安慰——人际沟通中的情感表达，
是雅思口语"感受类"问题的高分关键，也是真实社交的必备能力。

## 何时用到

- 表达感谢、道歉、赞美；
- 委婉拒绝、提出建议、安慰他人；
- 描述自己或他人的感受。

## 学习重点

1. **情感表达的准确与得体**：感谢、道歉的分寸；
2. **高情商表达**：拒绝带理由、建议带尊重；
3. **感受词汇的多样性**：摆脱 good/bad 的单一表达。
