# 情绪与关系表达 · 核心表达

## 一、感谢

**表达感谢**
- **【Thank you so much for … / I really appreciate …】**（非常感谢你…/我真的很感激…）
- **【Thanks for doing … — it made a big difference. / Thanks for … — it really helped.】**（谢谢你做…，作用很大）
- **【I'm grateful for … / I can't thank you enough for …】**（我感激…/对…感激不尽）

**回应感谢**
- **【You're welcome. / No problem at all.】**（不客气）
- **【I'm glad I could help. / Happy to help.】**（很高兴能帮上忙）

## 二、道歉

**表达道歉**
- **【I'm sorry about … / I apologise for …】**（对于…我很抱歉）
- **【I'm sorry I … — it was my mistake. / I'm sorry, that was my mistake.】**（很抱歉我…，是我的错）
- **【I feel bad about … / I feel terrible about …】**（我对…感到很抱歉）

**接受道歉**
- **【No worries — it happens. / Don't worry about it — it's okay.】**（没关系，这种事难免）
- **【I know you didn't mean it. / I know it wasn't on purpose.】**（我知道你不是故意的）

## 三、拒绝与建议

**委婉拒绝**
- **【I'm afraid I can't … / I'd rather not … if that's okay.】**（恐怕我不能…/我不太想…，如果可以的话）
- **【I'd love to, but … / I wish I could, but …】**（我很想，但…）

**提出建议**
- **【Have you thought about …? / What about …?】**（你考虑过…吗？/ …怎么样？）
- **【I'd suggest … / Maybe you could …】**（我建议…/也许你可以…）
- **【It might help to … / You could try …】**（…可能有帮助/你可以试试…）

## 四、安慰与感受

**安慰**
- **【I'm sorry to hear that. / That sounds tough.】**（听到这个我很难过/听起来很不容易）
- **【I'm here for you if you need to talk. / I'm here if you want to talk.】**（需要聊天的话我都在）
- **【Everything will work out. / Things will get better.】**（一切都会好起来的）

**感受词汇**
- **【I feel relieved / anxious / grateful / disappointed / optimistic.】**（我感到如释重负/焦虑/感激/失望/乐观）
- **【I can't help feeling … / I keep thinking about …】**（我忍不住觉得…/我一直在想…）

## 五、高频句型

- Thank you so much for …（非常感谢你…）
- I'm sorry about …（对于…我很抱歉）
- I'd love to, but …（我很想，但…）
- I'd suggest …（我建议…）

## 六、易错提醒

- 道歉要具体（I'm sorry about…），不空泛；
- 拒绝先表意愿再说明原因，保持关系；
- 感受词汇注意搭配：anxious about / grateful for / disappointed with。
