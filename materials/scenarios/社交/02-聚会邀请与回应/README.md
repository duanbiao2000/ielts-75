# 场景：聚会邀请与回应

## 场景定位

发出邀请、接受或婉拒邀请、确认细节——社交活动必备，
考察礼貌表达与"拒绝时不伤关系"的高情商表达。

## 何时用到

- 邀请朋友参加聚会、活动、聚餐；
- 接受或婉拒邀请；
- 确认时间、地点、细节。

## 学习重点

1. **发出邀请**：邀请的礼貌表达；
2. **接受与婉拒**：自然、得体、有理由；
3. **确认细节**：时间、地点、安排。

## 与现有资源的关联

- 词汇对接话题库「社会融入与社区」「人物与关系」；
- 婉拒表达可迁移到职场与生活沟通。
