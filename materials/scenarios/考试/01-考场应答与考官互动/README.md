# 场景：考场应答与考官互动

## 场景定位

雅思口语考试当天与考官的全流程互动：进入考场、问候、听题、回答、追问、结束道别。
这个场景的表达直接决定考场表现的"第一印象"与收尾质量。

## 何时用到

- 雅思口语考试全程（Part 1 开场与收尾、Part 2 过渡、Part 3 讨论、结束道别）；
- 任何与考官、面试官、面试官式人物的正式对话。

## 学习重点

1. **开场问候与结束道别**：自然得体，不过度热情；
2. **听题与确认**：没听清时如何礼貌请求重复，而不是假装听懂；
3. **回答的过渡**：用短句衔接（That's an interesting question / I haven't thought about that before）
   展示真实互动感，避免机械作答；
4. **保持自然节奏**：短句过渡 + 直接回答，不背稿。
