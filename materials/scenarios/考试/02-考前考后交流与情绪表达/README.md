# 场景：考前考后交流与情绪表达

## 场景定位

围绕考试的"前、中、后"全流程的表达：考前紧张与准备、考试中的自我调整、
考后交流结果与感受。情绪表达是雅思口语 Part 1/3 的隐形考点。

## 何时用到

- 与朋友、同学、老师谈论备考与考试；
- 表达紧张、放松、自信、失望、满意等情绪（Part 1/3 高频）；
- 描述自己的备考经历与考试结果。

## 学习重点

1. **情绪表达的多样性**：不只会说 nervous / happy，学会
   anxious, confident, relieved, overwhelmed 等更精准的词；
2. **描述过程与感受**：备考 → 考试 → 出结果，时间线清晰，
   过去时与现在时正确切换；
3. **表达变化与转折**：从紧张到放松、从担心到满意，
   体现语言的连贯性与真实感。

## 与现有资源的关联

- 情绪表达可迁移到任何"感受类"问题（经历、旅行、工作话题）；
- 配合第 3 课（A-R-E）与第 5 课（论证框架）使用。
