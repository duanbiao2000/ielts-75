# 场景：医疗与就诊

## 场景定位

描述症状、预约与就诊沟通、说明病情与用药——留学与移民生活的必备场景，
也是雅思听力与口语的常见话题（健康类）。

## 何时用到

- 身体不适时描述症状；
- 预约、看医生、向医生说明情况；
- 取药、询问医嘱、复诊。

## 学习重点

1. **症状描述**：部位 + 感受 + 持续时间的准确表达；
2. **就诊沟通**：向医生说明情况、理解医嘱；
3. **礼貌与清晰**：在紧张情境下依然表达清楚。
