# 购物与退换 · 情景对话与练习

> 【】内为可替换表达。

## 对话一：商店购物

**You**: Hi, I'm **【looking for a jacket. / interested in this jacket.】** Could you tell me how much it is?

**Assistant**: It's 120 yuan. We have it in blue and black.

**You**: I like the blue one. **【Do you have it in a larger size? / Could I try a size larger?】**

**Assistant**: Sure, here you go.

**You**: **【It fits well. I'll take it. / It fits perfectly. I'll go with this one.】**

**Assistant**: Will that be cash or card?

**You**: Card, please. **【Could you put it in a bag? / Could I have a bag, please?】**

## 对话二：退换货

**You**: Hi, I'd like to **【return this jacket. / return this item.】** **【It doesn't quite fit — it's a bit tight. / I bought it last week, but it doesn't fit properly.】**

**Assistant**: I'm sorry about that. Do you have the receipt?

**You**: Yes, here it is. **【Could I get an exchange for a larger size? / Would it be possible to exchange it for a larger size?】**

**Assistant**: Of course. Let me check the stock… Yes, we have a larger size.

**You**: Perfect, thank you. **【That's very helpful. / Thanks for your help.】**

## 练习任务

1. **角色扮演**：两人一组，完整走一遍"购物 → 询问 → 购买 → 退换"流程，角色互换；
2. **脱稿录音**：单人完成两段对话，注意问句的升调与礼貌语气；
3. **自测清单**：
   - 能否用不同方式询价与询问库存？
   - 退换时能否清晰说明原因并礼貌提出请求？
   - 能否用 I'd like to / Would it be possible 等委婉表达？
4. **迁移练习**：把购物表达与话题库「物品与活动」结合，录一段"描述一次满意的购物经历"。
