# 场景：购物与退换

## 场景定位

日常购物、询价、比较、砍价（适度）、退换货沟通——生活高频场景，
覆盖实体店与线上购物，表达实用且考试中常用于"消费/服务"类话题。

## 何时用到

- 商店、超市、线上平台购物；
- 询问价格、尺码、库存；
- 商品有问题时退换、投诉、维权。

## 学习重点

1. **询价与比较**：价格、尺码、库存的询问与比较表达；
2. **意见与选择**：表达偏好、做决定；
3. **售后沟通**：退换、维修、投诉的礼貌表达。

## 与现有资源的关联

- 词汇可对接话题库「物品与活动」「环境与社会议题」（消费话题）；
- 配合第 5 课论证框架，可延伸讨论消费习惯。
