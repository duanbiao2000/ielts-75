# 购物与退换 · 核心表达

## 一、购物询问

**询价与库存**
- How much is this? / What's the price?（这个多少钱？）
- Do you have this in a different size / colour?（这个有其他尺码/颜色吗？）
- Do you have this in stock?（这个有现货吗？）
- Do you offer any discounts?（有折扣吗？）

**比较与选择**
- I'm trying to choose between these two.（我想在这两个之间选一个）
- This one is a bit expensive. Do you have anything cheaper?（这个有点贵，有便宜点的吗？）
- I'll take this one. / I'll go with this one.（我要这个）

## 二、线上购物

- I'd like to order this online.（我想在线下单这个）
- Can I track my order?（能查物流吗？）
- When will my order be delivered?（什么时候能送到？）

## 三、退换与售后

**退货**
- I'd like to return this item.（我想退掉这个商品）
- It doesn't fit / work properly.（它不合身/不能正常使用）
- Could I get a refund or an exchange?（能退款或换货吗？）
- Do I need the receipt for the return?（退货需要小票吗？）

**投诉与维权**
- I'm not satisfied with this product.（我对这个产品不满意）
- The item arrived damaged.（商品到货时已损坏）
- I'd like to make a complaint about …（我想投诉…）
- Could you look into this for me?（能帮我调查处理一下吗？）

## 四、高频句型

- I was wondering if …（我想请问是否…）
- I'd like to …（我想…）
- Would it be possible to …?（能否…？）
- I'm looking for …（我在找…）

## 五、易错提醒

- 退换时说明原因（It doesn't fit / It arrived damaged），表达更清晰；
- 投诉保持礼貌但坚定，用 I'd like to 而非直接指责；
- "refund" 是退款，"exchange" 是换货，别混用。
