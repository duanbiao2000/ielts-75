# 场景：租房与居住沟通

## 场景定位

租房、看房、与房东/中介沟通、处理居住问题——留学与移民生活的必备技能，
也是雅思口语与听力的高频场景。

## 何时用到

- 找房、看房、咨询房源；
- 与房东或中介谈租金、设施、维修；
- 入住后反馈居住问题（噪音、维修、合同）。

## 学习重点

1. **询问与表达需求**：对房间、租金、设施的要求；
2. **谈判与确认细节**：租金、包含项目（水电网）、租期；
3. **问题反馈与投诉**：礼貌但明确地提出居住问题。
