# 场景：餐饮与点餐

## 场景定位

餐厅点餐、咨询菜品、特殊需求沟通、评价与反馈——留学、旅行、生活必备，
雅思听力 Section 1 也常考餐厅场景。

## 何时用到

- 餐厅、咖啡馆点餐；
- 提出饮食需求（素食、过敏、口味）；
- 评价菜品、反馈服务。

## 学习重点

1. **点餐流程表达**：看菜单、咨询、下单、要求；
2. **饮食需求表达**：过敏、素食、口味偏好，准确且礼貌；
3. **评价与反馈**：正向与负向的地道评价。

## 与现有资源的关联

- 词汇可对接话题库「健康与生活方式」（饮食）；
- 听力 Section 1 餐厅场景词汇互通。
