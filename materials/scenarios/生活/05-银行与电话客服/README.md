# 场景：银行与电话客服

## 场景定位

银行业务办理、电话客服沟通、处理账户与服务问题——生活与留学/移民的高频场景，
重点训练"电话沟通 + 问题处理"的表达，电话沟通对听力和口语都是考验。

## 何时用到

- 开户、查询账户、办理业务；
- 致电客服处理账单、故障、投诉；
- 电话沟通中的确认、转接、跟进。

## 学习重点

1. **电话开场与身份确认**：标准电话用语；
2. **业务描述与请求**：清晰说明需求；
3. **确认与跟进**：确认信息、记录工单、约定回复。

## 与现有资源的关联

- 词汇可对接话题库「生活服务」类表达；
- 配合第 2 课（连读弱读）听电话客服场景更轻松。
