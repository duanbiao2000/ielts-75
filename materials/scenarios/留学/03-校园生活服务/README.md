# 场景：校园生活服务

## 场景定位

图书馆、宿舍、教务、学生服务等校园办事场景——留学生活日常必备，
覆盖各类行政与生活服务沟通。

## 何时用到

- 图书馆借阅、宿舍报修、教务咨询；
- 学生服务中心办理各类事务；
- 校园活动、社团咨询。

## 学习重点

1. **服务咨询**：询问流程、材料、地点；
2. **问题处理**：报修、投诉、请求协助；
3. **服务评价**：正向与负向反馈。
