# 场景：申请与入学注册

## 场景定位

留学申请、与学校沟通、入学注册——留学必备场景，
雅思听力与口语常考，也是真实留学生活的第一关。

## 何时用到

- 咨询课程、提交申请、跟进进度；
- 入学注册、确认信息、办理入学手续；
- 与学校行政人员沟通。

## 学习重点

1. **申请沟通**：咨询、提交、跟进的表达；
2. **注册流程**：确认信息、材料、时间；
3. **正式邮件/电话用语**：礼貌、清晰、专业。

## 与现有资源的关联

- 词汇对接话题库「学业与专业」「留学适应」；
- 配合第 2 课语音，听学校行政沟通更轻松。
