# 场景：留学适应与跨文化沟通

## 场景定位

初到异国的适应、文化差异沟通、交友与融入——留学生的核心软技能场景，
直接对应雅思口语"移民动机与新生活""社会融入"类话题。

## 何时用到

- 描述文化差异、适应困难与应对；
- 与不同文化背景的人交流、化解误解；
- 结交朋友、融入当地生活。

## 学习重点

1. **描述文化差异**：客观、具体、不过度评判；
2. **表达适应过程**：困难 → 应对 → 收获；
3. **跨文化沟通**：澄清误解、表达尊重。

- 情绪表达可迁移到话题库「经历与故事」。
