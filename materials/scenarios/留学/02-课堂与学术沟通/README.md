# 场景：课堂与学术沟通

## 场景定位

课堂讨论、向教授提问、汇报作业、学术邮件——留学学术生活的核心场景，
雅思口语 Part 3（学术讨论）与听力 Section 3 直接相关。

## 何时用到

- 课堂发言、小组讨论、向老师提问；
- 提交作业、咨询论文、预约答疑；
- 写学术邮件。

## 学习重点

1. **课堂发言**：观点表达、提问、回应；
2. **学术咨询**：向教授提问、预约、咨询作业；
3. **学术邮件**：正式、清晰、礼貌的书面表达。
