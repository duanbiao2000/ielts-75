# 雅思口语场景库 · 使用指南

> 定位：在 16 个话题文件夹（解决"考什么"）之外，场景库解决"**说什么、怎么说**"——
> 覆盖考试、生活、职场、出行、留学、旅行、社交七大领域，30 个高频场景，
> 每个场景提供可直接采纳使用的表达与对话。

## 一、场景库结构（`scenarios/`）

按七大领域分 30 个场景，**一个场景 = 一个文件夹**，固定 3 个文件：

| 文件 | 内容 |
| --- | --- |
| `README.md` | 场景定位、何时用到、学习重点、与 11 课/话题库的关联 |
| `01-核心表达.md` | 场景高频词、"开口就说"基础句型、进阶表达、易错提醒 |
| `02-情景对话与练习.md` | 2 段实战对话（中英对照，标注可替换表达）+ 角色扮演与自测任务 |

**30 个场景清单**：

- **考试**：考场应答与考官互动、考前考后交流与情绪表达
- **生活**：租房与居住沟通、购物与退换、餐饮与点餐、医疗与就诊、银行与电话客服
- **职场**：面试与自我介绍、入职与日常沟通、会议与汇报、请假加班与离职沟通、
  客户沟通与商务洽谈、演示与公开表达、电话与线上会议、商务社交与应酬、
  投诉处理与应急沟通、培训与带教
- **出行**：机场与航班、酒店入住与退房、交通与问路、旅行突发情况
- **留学**：申请与入学注册、课堂与学术沟通、校园生活服务、留学适应与跨文化沟通
- **旅行**：行程规划与预订、旅行中的社交与体验
- **社交**：日常寒暄与介绍、聚会邀请与回应、情绪与关系表达

> 注：职场域后 6 个场景（客户沟通与商务洽谈、演示与公开表达、电话与线上会议、
> 商务社交与应酬、投诉处理与应急沟通、培训与带教）为业务应用导向的扩展场景，
> 面向企业员工推广使用，覆盖对外沟通、公开表达与带教管理等高频业务场景。

## 二、三种用法

### 用法 A：日常积累（推荐顺序）
按领域逐个场景学习，每个场景：
1. 读 README 了解场景与重点；
2. 背核心表达（先记"开口就说"部分）；
3. 角色扮演或脱稿录音对话；
4. 完成自测清单，把易错点记入 learning-records。

### 用法 B：考试对接
- **考场应答**：直接用于考试当天的流程互动；
- **面试/学术沟通**：迁移到口语 Part 1（工作、学习）与 Part 3 讨论；
- **情绪表达**：迁移到任何"感受类"问题（经历、旅行、适应）；
- **场景句型**：填充到话题库对应话题的回答中，让回答更具体、更地道。

### 用法 C：与话题库联动
场景库（表达）+ 话题库（话题与结构）配合使用：
- 学话题库时，用场景库的句型做素材；
- 学场景库时，用话题库的结构组织回答；
- 冲刺期：只练"场景句型 + 话题卡"的快速组合，模拟临场输出。

## 三、练习纪律

1. **开口优先**：每个场景的对话必须录音或角色扮演，只读不练无效；
2. **替换练习**：对话中【】内为可替换表达，主动替换，形成自己的版本；
3. **迁移意识**：每学一个场景，想一个"这个表达还能用在什么话题/场景"；
4. **记录卡点**：发音、用词、流畅度的卡点写进 learning-records，冲刺期复习。

## 四、与 11 课的对应

| 课程 | 场景库用法 |
| --- | --- |
| 第 2 课 连读弱读 | 朗读场景对话，体会连读与弱读 |
| 第 3 课 A-R-E | 用场景句型做 A-R-E 回答的素材 |
| 第 4 课话题卡 | 场景故事（如面试、旅行）作为话题卡素材 |
| 第 5 课论证 | 会议、面试场景的观点表达迁移到 Part 3 |
| 第 9 课发音 | 跟读场景对话，打磨语调与节奏 |
| 第 11 课模考 | 抽取场景库做完整口语模拟的素材库 |
