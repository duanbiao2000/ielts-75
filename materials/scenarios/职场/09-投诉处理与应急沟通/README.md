# 投诉处理与应急沟通

## 场景定位

面向问题与危机的沟通场景：客户投诉处理、服务失误应对、业务突发状况的沟通。
与「旅行突发情况」（旅行域）互补，本场景聚焦**业务场景下的应急沟通**——
在对方情绪激动或时间紧迫时，稳住局面、推进解决。

## 何时用到

- 客户投诉、服务失误的应对；
- 业务突发状况（延期、故障、差错）的沟通与通报；
- 需要安抚情绪、解释原因、给出方案的时刻；
- 口语考试中迁移到 Part 2（一次困难的经历/处理问题的经历）与 Part 3（服务与责任议题）。

## 学习重点

1. **情绪优先**：先安抚情绪、表达理解，再处理问题——顺序不能反；
2. **识别核心诉求**：把对方的抱怨提炼成具体诉求，确认理解；
3. **方案表达**：给出可执行的解决方案与时间承诺，不空泛承诺；
4. **压力下的清晰**：应急场景语速易乱，刻意保持节奏与结构。

## 与 11 课及话题库关联

- 第 5 课（论证语料）：解释原因、说明方案的结构迁移；
- 第 9 课（发音）：压力下保持发音清晰，是应急沟通的基础；
- 模块 09（考场表现）：压力管理与卡顿恢复，同构于应急沟通的稳住节奏；
- 话题库：移民工作·06-环境与社会议题（责任议题）、移民工作·05-健康与生活方式；
- 相关场景：客户沟通与商务洽谈（异议升级为投诉时）、购物与退换（基础投诉表达）。
