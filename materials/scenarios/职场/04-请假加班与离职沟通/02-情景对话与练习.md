# 请假、加班与离职沟通 · 情景对话与练习

> 【】内为可替换表达。

## 对话一：请假

**You**: Hi, **【I'd like to ask for a day off on Friday. / I'd like to take Friday off, if that's possible.】**

**Manager**: Of course. What's the reason?

**You**: **【I'm feeling a bit unwell, so I need to see a doctor and rest. / I'm not feeling well, so I need to see a doctor.】** **【I'll make sure my work is covered before I'm away. / I'll arrange for my tasks to be covered.】**

**Manager**: That's fine, go ahead.

**You**: **【Thank you. / I appreciate it.】**

## 对话二：加班协商

**Manager**: We have a deadline this Friday. Could you work overtime to finish it?

**You**: **【Sure, I'm happy to stay late this week. / Of course, I can stay late this week.】** **【Could I take the time off as compensatory leave later? / Would it be possible to take the time back as time in lieu?】**

**Manager**: Yes, that's fine.

**You**: Thank you. **【I'll make sure the work is done on time. / I'll get it done by the deadline.】**

## 对话三：离职

**You**: I'd like to **【talk to you about my resignation. / discuss my decision to leave the company】**. I've decided to **【resign / move on to a new opportunity】**, and my last day would be **【…】**.

**Manager**: I'm sorry to hear that. Is there anything we can do to change your mind?

**You**: **【Thank you, but I've made up my mind. / It's a difficult decision, but I've decided.】** I'd like to thank you for **【the opportunity and support / everything you've done for me】**. **【I'll make sure to complete the handover properly. / I'll hand over all my work properly.】** It's been a great experience working here.

**Manager**: Thank you for your contribution. We'll arrange the handover.

## 练习任务

1. **角色扮演**：两人一组，完成"请假、加班协商、离职"三段对话，角色互换；
2. **脱稿录音**：单人完成三段对话，注意不同场景的语气差异（请假礼貌、离职正式）；
3. **自测清单**：
   - 请假能否清晰说明原因、时间，并主动提出工作衔接？
   - 加班协商能否表达意愿与调休诉求？
   - 离职表达是否得体、不情绪化？
4. **迁移练习**：把请假表达与话题库「工作与职业」结合，
   录一段"工作与生活的平衡"的回答。
