# 请假、加班与离职沟通 · 核心表达

## 一、请假

**请假请求**
- I'd like to ask for **【a day off / some time off】** on **【…】**.（我想请…（某天）…假）
- I need to take some leave for **【…】**.（我需要为…请假）
- Could I take **【a day off / a few hours off】** next week?（下周能请…假吗？）

**说明原因**
- I'm feeling a bit unwell, so I need to **【see a doctor / rest for a day】**.（我有点不舒服，需要看医生/休息一天）
- I have a **【family matter / personal matter】** to attend to.（我有些家事/私事要处理）

**确认与交接**
- I'll make sure my work is covered before I'm away.（我离开前会安排好工作衔接）
- **【Could you approve my leave? / I'd appreciate it if you could approve it.】**

## 二、加班与调休

- I'm happy to **【work overtime / stay late】** this week.（我本周乐意加班）
- I might need to **【work overtime / stay a bit late】** to finish the task.（我可能需要加班完成任务）
- Could I take the time off **【as time in lieu / as compensatory leave】**?（能否调休？）

## 三、离职沟通

**提出离职**
- I've decided to **【resign from my position / leave the company】**.（我决定离职）
- I'd like to submit my resignation.（我想提交辞呈）
- My last day would be **【…】**.（我的最后一天是…）

**感谢与交接**
- I'd like to thank you for the opportunity and support.（感谢您给的机会与支持）
- I'll make sure to **【hand over my work / complete the handover】** properly.（我会妥善交接工作）
- It's been a great experience working here.（在这里工作是一段很好的经历）

## 四、高频句型

- I'd like to ask for …（我想请…）
- Could I …?（能否…？）
- I'd appreciate it if …（如果…我将不胜感激）
- I'd like to …（我想…）

## 五、易错提醒

- 请假先说明原因与时间，再请求批准，顺序清晰；
- 离职表达要正式得体，避免情绪化；
- 加班用 work overtime / stay late，调休用 time in lieu 或 compensatory leave。
