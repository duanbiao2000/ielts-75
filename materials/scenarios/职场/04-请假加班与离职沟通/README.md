# 场景：请假、加班与离职沟通

## 场景定位

请假、加班协商、调休、离职交接——职场中敏感且需要高情商的沟通场景，
表达要礼貌、清晰、有依据。

## 何时用到

- 请病假、事假、年假；
- 协商加班与调休；
- 提出离职、工作交接。

## 学习重点

1. **请假表达**：原因 + 时间 + 请求批准；
2. **加班协商**：说明情况、表达意愿或困难；
3. **离职沟通**：正式、得体、有交接意识。

## 与现有资源的关联

- 词汇可对接话题库「工作与职业」；
- 请假/加班表达可迁移到生活场景（与医生、学校的沟通）。
