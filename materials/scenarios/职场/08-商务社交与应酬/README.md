# 商务社交与应酬

## 场景定位

商务场合的社交场景：商务寒暄、应酬交谈、活动交流、宴请对话。
与私人社交（社交域 3 场景）互补，本场景聚焦**商务语域下的轻松交流**——
轻松但不随意，自然但有分寸。

## 何时用到

- 商务接待、宴会、酒会、展会交流；
- 与客户、合作伙伴的餐叙与寒暄；
- 活动场合结识同行、建立联系；
- 口语考试中迁移到 Part 1（社交习惯）与 Part 3（人脉与社交议题）。

## 学习重点

1. **寒暄话题**：安全话题（行程、行业动态、活动感受）的选择；
2. **自然过渡**：从寒暄到业务的转接（不突兀、不硬推销）；
3. **分寸感**：商务语域下的轻松——不问隐私、不过度随意；
4. **收尾与跟进**：礼貌结束对话、表达后续联系意愿。

## 与 11 课及话题库关联

- 第 3 课（Part 1 聊天体）：商务寒暄是"聊天体 + 商务语域"的组合；
- 模块 03（语域意识）：商务社交的语域分寸是重点训练项；
- 第 4 课（话题卡）：一次成功的商务社交可作为 Part 2 素材；
- 话题库：通用·01-人物与关系、移民工作·02-职场与同事；
- 相关场景：日常寒暄与介绍（私人版基础）、客户沟通与商务洽谈（转入正题后的沟通）。
