# 场景：面试与自我介绍

## 场景定位

面试全流程的表达：自我介绍、回答求职动机与能力问题、提问与收尾。
这是移民工作类与雅思口语 Part 1（工作话题）的直接对接场景。

## 何时用到

- 工作面试、入学申请面试、签证面谈；
- 任何需要"介绍自己"的正式场合。

## 学习重点

1. **自我介绍结构**：基本信息 → 背景经历 → 与职位的契合点 → 收尾；
2. **高频面试问题**：动机、优势、缺点、职业规划的应答框架；
3. **收尾表达**：提问、感谢、跟进。

## 与现有资源的关联

- 词汇可对接话题库「工作与职业」「职场与同事」；
- 自我介绍结构与第 4 课话题卡结构（开场-主体-收尾）一致。
