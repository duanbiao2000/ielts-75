# 电话与线上会议

## 场景定位

远程协作时代的高频沟通场景：电话业务沟通、视频会议发言与互动。
覆盖"无画面/弱信号"条件下的口头交流——靠语音本身完成全部沟通。

## 何时用到

- 电话客户沟通、电话会议；
- 视频会议中的发言、提问、总结；
- 信号不佳、延迟、打断等线上特有状况；
- 口语考试中迁移到 Part 1（日常沟通习惯）与 Part 3（远程办公议题）。

## 学习重点

1. **电话开场与收尾**：自报家门、说明来意、确认对方方便、礼貌收尾；
2. **发言信号**：想发言时的切入表达、确认发言完毕的收束；
3. **听不清与延迟**：请求重复、确认理解、技术问题的应对；
4. **声音状态**：无画面时，语调与重音承担全部表达力，要更主动。

## 与 11 课及话题库关联

- 第 2 课（连读弱读）：电话语音密度高，连读弱读的识别与运用直接相关；
- 第 8 课（Section 3–4）：学术讨论场景与线上会议发言同构；
- 第 9 课（发音）：无画面时发音清晰度权重更高；
- 话题库：移民工作·02-职场与同事、01-工作与职业；
- 相关场景：客户沟通与商务洽谈（电话版客户沟通）、银行与电话客服（电话沟通基础）。
