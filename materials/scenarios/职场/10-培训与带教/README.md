# 培训与带教

## 场景定位

管理与骨干人群的高频口语场景：内部培训授课、带教新人、
传授经验与技能、指导与反馈。本场景把"教别人"这一职场核心口语能力
系统化——讲得清、引得动、反馈准。

## 何时用到

- 内部培训、分享会、经验传授；
- 带教新人、指导下属或后辈；
- 工作交接、技能传承；
- 口语考试中迁移到 Part 2（Describe a time you taught someone something）
  与 Part 3（教育与指导议题）。

## 学习重点

1. **讲解结构**：概念 → 示例 → 练习，像"迷你演示"一样组织；
2. **引导而非包办**：先让对方尝试与思考，用提问引导，不直接给答案；
3. **反馈技术**：对对方表现给具体反馈（证据 + 建议），与主管反馈模板同构；
4. **语域分寸**：带教是"指导式交谈"——比演示松弛、比闲聊有结构。

## 与 11 课及话题库关联

- 第 4 课（话题卡结构）：讲解流程/经验的结构迁移；
- 第 5 课（论证语料）：解释原因、说明方法的表达；
- 模块 11（考官视角与反馈模板）：反馈技术同构——先给证据、再给动作；
- 模块 03（语域意识）：带教语域的分寸把握；
- 话题库：通用·02-经历与故事（经验传承类故事素材）、移民工作·02-职场与同事；
- 相关场景：演示与公开表达（讲解的"公开版"）、会议与汇报（指导后的跟进）。
