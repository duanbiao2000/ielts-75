# 客户沟通与商务洽谈

## 场景定位

对外业务沟通的核心场景：客户拜访、需求沟通、方案介绍、商务谈判、
分歧协商。本场景补全职场域长期缺失的**对外沟通**维度。

## 何时用到

- 客户会议、商务洽谈、提案沟通；
- 电话/线上的客户沟通（与「电话与线上会议」配合）；
- 处理客户异议、协商条件（价格、工期、条款）；
- 口语考试中迁移到 Part 1（工作类）与 Part 2（经历类：一次成功的谈判/客户沟通）。

## 学习重点

1. **谈判框架**：开场定调 → 说明立场 → 回应异议 → 让步与条件交换；
2. **语气控制**：坚定与礼貌的平衡——既不让步过度，也不生硬；
3. **轮次管理**：表达完主动交还话语权（What are your thoughts?）；
4. **异议处理**：先认可对方观点，再给出理由或替代方案。

## 与 11 课及话题库关联

- 第 5 课（论证语料）：谈判中解释理由、回应异议的结构迁移；
- 第 4 课（话题卡）：客户沟通经历可作为 Part 2 素材；
- 话题库：移民工作·01-工作与职业、02-职场与同事；
- 相关场景：电话与线上会议（电话版客户沟通）、投诉处理与应急沟通（异议升级时）。
