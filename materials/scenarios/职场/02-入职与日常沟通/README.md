# 场景：入职与日常沟通

## 场景定位

入职适应、日常工作沟通、与上级同事的日常协作——职场高频场景，
覆盖从第一天入职到日常协作的完整表达。

## 何时用到

- 入职第一天、熟悉团队与流程；
- 日常工作汇报、请求协助、确认任务；
- 与同事、上级的日常沟通。

## 学习重点

1. **入职沟通**：介绍、确认职责、了解流程；
2. **任务沟通**：请求、确认、汇报、跟进；
3. **团队协作**：合作、求助、反馈。

## 与现有资源的关联

- 词汇可对接话题库「工作与职业」「职场与同事」；
- 配合第 3 课 A-R-E，让工作沟通表达更完整。
