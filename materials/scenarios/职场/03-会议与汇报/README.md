# 场景：会议与汇报

## 场景定位

会议发言、观点表达、汇报工作进展——职场核心场景，
对雅思口语 Part 3（论证与表达观点）有直接迁移价值。

## 何时用到

- 参加会议、发表观点、回应他人；
- 汇报工作进展、项目情况；
- 主持或参与讨论、做总结。

## 学习重点

1. **观点表达**：同意/不同意/部分同意，展示论证能力；
2. **会议发言**：开场、补充、总结、提问；
3. **汇报结构**：进度 → 结果 → 问题 → 下一步。

## 与现有资源的关联

- 观点表达可直接迁移到第 5 课论证框架（观点→解释→举例→让步）；
- 词汇对接话题库「工作与职业」。
