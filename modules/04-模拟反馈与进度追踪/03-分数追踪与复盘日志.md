# 分数追踪与复盘日志

> 目标：让进步可见、错误可追、改进可验证。
> 建立个人学习档案，作为长期项目的核心资产。

## 一、分数追踪表

每次模考记录一行，长期累积，直观看到进步曲线。

| 日期 | Part1 | Part2 | Part3 | 流利 | 词汇 | 语法 | 发音 | 综合 | 最大短板 | 状态 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| （示例） | 7 | 7 | 6.5 | 7 | 7 | 6.5 | 7 | 6.8 | 语法结构单一 | 强化中 |
| | | | | | | | | | | |

**填写说明**：
- 各维度按 1–9 打分（可到 0.5），Part 1/2/3 为整体印象分；
- 综合 = 四维度平均；最大短板对应到具体维度；
- 状态：基础期 / 强化期 / 冲刺期 / 已达标。

## 二、复盘日志模板

每次模考后填写，按"事实 → 归因 → 改进 → 验证"四步走。

### 第 N 次模考复盘（日期：____）

**1. 事实（客观结果）**
- 综合分：____；各维度：流利__ / 词汇__ / 语法__ / 发音__
- 录音中的典型问题（引用具体表现）：______

**2. 归因（为什么会这样）**
- 错因分类（选填）：知识缺失 / 语音听不懂 / 粗心失误 / 时间与节奏 / 其他
- 深层原因：______

**3. 改进（下一步做什么）**
- 针对短板，安排到具体模块训练：
  - 发音问题 → 模块 01 发音深度训练（具体练____）
  - 流利问题 → 模块 02 流利度专项（具体练____）
  - 词汇问题 → 模块 03 词块与同义替换（具体练____）
  - 语法问题 → 模块 05 语法系统强化（具体练____）
- 改进动作要具体、可执行：______

**4. 验证（下次模考检查）**
- 下次模考时重点检查：______
- 目标：该短板维度分数提升至 ____

## 三、改进验证机制

1. **单点改进**：一次只改 1–2 个最大短板，避免贪多；
2. **两周验证**：改进动作执行 2 周后，用同一类型题模考，检查短板是否改善；
3. **未改善则换方法**：若改进后无变化，分析原因（方法不对/训练量不足），
   调整策略后重新验证；
4. **达标确认**：连续两次模考综合达 7.5 档，视为该阶段达标，进入下一阶段。

## 四、长期档案的价值

- 冲刺期：直接翻看历史短板与改进记录，精准复习，不做无效训练；
- 考后：档案是完整学习记录，可用于总结方法论；
- 长期：分数曲线让进步"看得见"，是坚持的最大动力。

## 五、与 agent 反馈的配合

- 模考录音或文字稿发给 agent，获取逐句反馈；
- agent 的反馈与自评对照，可发现自评盲区（如发音自己听不出的问题）；
- 反馈结果同样记入复盘日志，形成"自评 + 外部反馈"双通道。
