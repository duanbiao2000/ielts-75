# 四维度自评表

> 用途：每次模考录音后，按官方评分四维度打分（1–9），定位短板。
> 每项对照"7.5 档描述"自查：做到 7.5 要求即打 7.5，未达到则如实降档。

## 维度 1：流利度与连贯（Fluency & Coherence）

**7.5 档要点**：能长时间表达，偶有迟疑/重复/自我纠正；衔接手段多样；语速自然。

- [ ] 能持续表达较长篇幅，不频繁中断
- [ ] 迟疑、重复、自我纠正较少且自然
- [ ] 使用了多种衔接手段（连接词、过渡句）
- [ ] 语速自然，节奏连贯，没有"逐词蹦"或"卡顿填空"
- [ ] 回答结构清晰，听者能跟上逻辑

## 维度 2：词汇（Lexical Resource）

**7.5 档要点**：词汇运用灵活，能自如转述；有部分不常见搭配；偶有搭配/拼写错误但不影响理解。

- [ ] 使用了话题相关的合适词汇，不空泛
- [ ] 有搭配意识（collocation），不是单词堆砌
- [ ] 能转述（一个意思多种说法），不重复
- [ ] 使用了不常见/较地道的表达
- [ ] 用词准确，无明显搭配错误

## 维度 3：语法（Grammatical Range & Accuracy）

**7.5 档要点**：能使用多种复杂结构；偶有错误但不影响理解；时态、一致性基本正确。

- [ ] 使用了简单句与复杂句的混合（从句、条件句、被动等）
- [ ] 复杂结构使用正确，不影响理解
- [ ] 时态使用正确（经历过去时、现状现在时等）
- [ ] 无明显主谓一致、单复数、冠词错误
- [ ] 句子结构多样，不是全简单句

## 维度 4：发音（Pronunciation）

**7.5 档要点**：能运用多种发音特征；整体清晰可懂；偶有偏差不影响理解。

- [ ] 单词重音与句子重音正确、自然
- [ ] 语调有功能（陈述降调、疑问升调等）
- [ ] 节奏连贯，有连读弱读，整体可懂度高

## 使用说明

- 自评时**对照 7.5 档描述**逐条打分，避免"感觉不错"式主观高估；
- 卡点记录要具体（如"Part 3 时从句使用少"而非"语法不好"）；
- 每次自评后，把短板与模块 01–03 的训练内容对应，形成改进动作。
