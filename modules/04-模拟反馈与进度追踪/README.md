# 模块 4：模拟反馈与进度追踪

## 模块定位

把"练过"变成"**验证过**"：建立完整的模考、自评、追踪、复盘闭环，
让进步可见、短板可查、反馈可落地。

## 为什么需要这个模块

- 没有模考验证，训练效果无法判断（"感觉练了很多"≠"分数涨了"）；
- 没有量化追踪，无法看到进步曲线，也难以定位具体短板；
- 没有复盘机制，同样的错误会反复出现；
- 本模块为整个长期项目提供**反馈与验证的基础设施**。

## 使用建议

- **每周 1 次完整模考**（严格按流程），每月 2–3 次；
- 每次模考后：自评 → 记录分数 → 写复盘日志；
- 复盘按"错因 → 改进 → 验证"循环，把改进项落实到具体模块（发音、流利、词块等）；
- 冲刺期：模考频率提高到每周 2 次，直到连续两次达标。
