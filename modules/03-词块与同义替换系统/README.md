# 模块 3：词块与同义替换系统

## 模块定位

从"单词量"升级到"**词块量**"与"**表达变化**"，解决词汇维度上 6.5 → 7.5 的关键：
词汇运用灵活、能自如转述、表达不重复。

## 为什么需要这个模块

- 7.5 词汇维度考的不是生僻词，而是**搭配的准确 + 表达的灵活**；
- 中国学习者最常见的问题是"知道单词、不会搭配"（如 do a decision）；
- "一个意思只会一种说法"（important 反复用）是词汇分被压在 6.5 的主因；
- 词块（collocation）是流利度和语法多样性的天然支撑。

## 使用建议

- **每日 10–15 分钟**：背 5–8 个词块，并**用它们造句或回答一个问题**；
- 优先掌握 `01` 功能词块库（表达框架的"弹药"），再扩展 `02` 同义替换；
- 所有词块**放进 Anki**，按间隔复习；
- 在场景库对话和话题库回答中**刻意使用**新词块，形成主动运用习惯。
