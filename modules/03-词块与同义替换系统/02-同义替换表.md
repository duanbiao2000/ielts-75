# 同义替换表

> 目标：一个意思掌握多种表达，避免重复，实现"自如转述"（7.5 词汇维度的核心）。
> 用法：每次表达时，刻意从表里挑一个"非第一反应"的词。

## 一、评价与态度

| 意思 | 表达 |
| --- | --- |
| 重要的 | important, essential, crucial, vital, significant |
| 好的/优秀的 | good, excellent, outstanding, remarkable, impressive |
| 差的/不好的 | bad, poor, inadequate, unsatisfactory, disappointing |
| 有挑战的 | challenging, demanding, tough, rigorous |
| 有收获的 | rewarding, worthwhile, valuable, enriching |
| 有趣的 | interesting, fascinating, engaging, absorbing |

## 二、程度与数量

| 意思 | 表达 |
| --- | --- |
| 很多 | a lot of, plenty of, numerous, a large number of, countless |
| 一些 | some, a few, a number of, several |
| 非常 | very, extremely, incredibly, quite, rather |
| 逐渐地 | gradually, slowly, over time, little by little |

## 三、常见动词

| 意思 | 表达 |
| --- | --- |
| 喜欢 | like, enjoy, be fond of, be keen on, be into |
| 使用 | use, utilise, make use of, take advantage of |
| 影响 | affect, influence, have an impact on, shape |
| 帮助 | help, assist, support, contribute to |
| 解决 | solve, resolve, address, tackle |
| 导致 | cause, lead to, result in, bring about |
| 认为 | think, believe, consider, hold the view that, in my opinion |

## 四、常用名词与概念

| 意思 | 表达 |
| --- | --- |
| 机会 | opportunity, chance, prospect, possibility |
| 问题 | problem, issue, challenge, difficulty, obstacle |
| 原因 | reason, factor, cause, motive |
| 影响 | effect, impact, consequence, influence |
| 变化 | change, shift, transformation, development |
| 技能 | skill, ability, capability, expertise |

## 五、过渡与逻辑

| 意思 | 表达 |
| --- | --- |
| 首先 | first of all, to begin with, initially, firstly |
| 然后 | then, after that, subsequently, next |
| 另外 | also, in addition, besides, furthermore |
| 但是 | but, however, nevertheless, that said, on the other hand |
| 因此 | so, therefore, thus, as a result, consequently |

## 六、替换练习方法

1. **一句话三版本**：同一意思，用表中 3 个表达各写一句话；
2. **录音替换**：录一段回答，回听时把重复的词标记，用替换表改写后再录；
3. **同义转述**：把一个句子换 2–3 种说法（练"自如转述"，直接对应 7.5 词汇要求）；
4. **Anki 建卡**：正面意思、背面 3–5 个表达，随机抽背。

## 七、目标

- 表达时"第一反应词"之外，至少有 2–3 个备选；
- 连续 20 句表达中，不出现 3 次以上同一词的重复；
- 转述一个意思时，能自然说出 2 种以上不同说法。
