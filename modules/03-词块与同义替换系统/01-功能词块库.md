# 功能词块库

> 按表达功能分类的固定搭配（collocations）。
> 用法：背下来 → 造句 → 在回答中刻意使用。这些词块是"表达框架的弹药"。

## 一、表达观点

| 词块 | 用法示例 |
| --- | --- |
| I'd say that … | I'd say that technology has made life easier. |
| From my point of view, … | From my point of view, teamwork matters most. |
| As far as I'm concerned, … | As far as I'm concerned, travel broadens the mind. |
| It seems to me that … | It seems to me that education is the key. |
| I firmly believe that … | I firmly believe that practice makes perfect. |
| To be honest, … | To be honest, I was a bit nervous at first. |

## 二、让步与转折

| 词块 | 用法示例 |
| --- | --- |
| That said, … | That said, it has its downsides too. |
| On the other hand, … | On the other hand, small towns are calmer. |
| Although …, … | Although it's challenging, I enjoy it. |
| It's true that …, but … | It's true that it takes time, but it's worth it. |
| Despite …, … | Despite the difficulties, we succeeded. |

## 三、举例与支撑

| 词块 | 用法示例 |
| --- | --- |
| For example, … | For example, many people work from home now. |
| Take … for instance. | Take online shopping for instance. |
| A good case in point is … | A good case in point is public transport. |
| What matters most is … | What matters most is staying consistent. |

| 词块 | 用法示例 |

## 六、比较与程度

| 词块 | 用法示例 |
| --- | --- |

| … is far more … than … | Reading is far more relaxing than gaming. |
| It varies from person to person. | It varies from person to person. |

## 七、总结与收尾

| 词块 | 用法示例 |
| --- | --- |
| To sum up, … | To sum up, the benefits outweigh the drawbacks. |
| In conclusion, … | In conclusion, it's a valuable experience. |
| Overall, … | Overall, I'm satisfied with the result. |
| Looking back, … | Looking back, I'm glad I made the decision. |

## 使用纪律

1. **每天 5–8 个**，不要贪多，重在运用；
2. **造句优先于背诵**：每个词块造一个与自己生活相关的句子；
3. **刻意使用**：在场景库对话、话题库回答中，替换掉原来的简单表达；
4. **间隔复习**：进 Anki，按"会用"标准复习，而不是"认识"。
