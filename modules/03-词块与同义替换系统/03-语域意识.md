# 语域意识（正式与非正式）

> 目标：根据场合选择正确的表达风格，避免"考场用俚语、日常太正式"的语域错位。
> 语域（register）是 7.5 词汇运用"得体性"的隐形加分项。

## 一、什么是语域

语域 = 语言的"场合感"：同样的意思，在正式场合（面试、考试、学术）和
非正式场合（朋友闲聊）用不同的表达。

**判断标准**：听者/读者能否通过你的用词，准确判断场合与关系。

## 二、正式 vs 非正式对照表

### 打招呼与开场
| 正式 | 非正式 |
| --- | --- |
| Good morning. | Hi / Morning. |
| I'd like to ask … | Can I ask …? |
| I would appreciate it if … | Could you …? / Can you …? |

### 请求与建议
| 正式 | 非正式 |
| --- | --- |
| I'd like to request … | I need / I want … |
| Would it be possible to … | Can we …? / Could we …? |
| I'd suggest … | Maybe … / How about …? |

### 表达观点
| 正式 | 非正式 |
| --- | --- |
| From my perspective, … | I think … / I guess … |
| I firmly believe that … | I'm pretty sure … / I'm sure … |
| It appears that … | It looks like … |

### 拒绝与委婉
| 正式 | 非正式 |
| --- | --- |
| I'm afraid I can't … | I can't really … / I'd rather not … |
| Unfortunately, … | Sorry, but … |

## 三、雅思口语中的语域应用

**考场是"半正式"场合**：
- 用**正式偏中**的表达：I'd like to, Could you, I'd say that, From my perspective；
- **避免过度口语化**：gonna, wanna, kind of, stuff, thing 等少用或不用；
- **避免过度书面化**：不用复杂长句堆砌，保持自然的对话感。

**判断口诀**：考场上说"礼貌、自然、有结构"的话，像和一个专业人士认真交流，
而不是像和朋友闲聊，也不是像在写论文。

## 四、训练方法

1. **场合改写**：把一句非正式的话改写为正式版本（反之亦然），练语域切换；
2. **录音检查**：录音时留意是否混入过多口语化表达（gonna, stuff, kind of）；
3. **场景对练**：场景库的"面试""银行客服""课堂学术"等偏正式场景，
   刻意使用正式表达；"朋友闲聊"场景用自然口语，感受差异；
4. **语域清单自检**：回答前快速判断"这个场合该正式还是自然"。

## 五、常见误区

- ❌ 考场用俚语装"地道"：反而显得不正式，扣分；
- ❌ 考场全用简单句+口语词：显得语言控制力弱；
- ✅ 考场用"半正式"表达：既自然又有语言质量。

## 六、目标

- 能根据场合自动选择语域，不混用；
- 考场表达统一在"半正式"区间，得体自然；
- 在场景库不同场景中，语域切换自如。
