# 语法多样性训练

> 目标：让复杂结构**自然融入**表达，而不是"为了复杂而复杂"。
> 7.5 语法维度要求：多种复杂结构 + 偶尔小错不影响理解。

## 一、什么是"语法多样性"

- 不是句子越长越复杂越好；
- 而是**简单句与复杂句的合理混合**：有简单句保证清晰，
  有复杂句展示语言控制力；
- 评判标准：听者能感受到你"能驾驭不同结构"，且表达自然。

## 二、训练方法

### 方法 1：结构植入法
每次回答时，**刻意植入 1–2 个复杂结构**：
- 定语从句：I'm studying …, **which** …
- 条件句：**If** I …, I **would** …
- 完成时：**I've been** … for …
- 让步：**Although** …, I …

训练步骤：
1. 选定一种结构；
2. 在回答 3–4 个问题时，每个回答都植入该结构；
3. 录音回听，确认结构使用正确且自然。

### 方法 2：升级练习（简单句 → 复杂句）
把自己写的简单句升级为复杂句：
- 简单句：I like reading. It relaxes me.
- 升级：I like reading, **which** really relaxes me.
- 简单句：I'll work hard. I'll succeed.
- 升级：**If** I work hard, I **will** succeed.

每天做 5 组升级练习，练"用结构重组表达"的能力。

### 方法 3：结构日记
每天用当天学的 2 个结构写 3–4 句话（与自己生活相关），
第二天录音朗读并自查。坚持 3–4 周，结构运用会自动化。

### 方法 4：示范回答拆解
把话题库/场景库的示范回答拆开，分析每句的结构：
- 这句用了什么结构？为什么这样用？
- 换成简单句会损失什么？
- 在自己的回答中模仿这种结构。

## 三、多样性检查清单

每次录音后问自己：
- [ ] 我用了至少 1 个复杂结构（从句/条件句/完成时等）吗？
- [ ] 复杂结构使用正确吗？
- [ ] 简单句与复杂句搭配合理吗（不是全简单句，也不是全长句）？
- [ ] 表达自然，不是为了用结构而硬塞吗？

## 四、避免的误区

- ❌ **堆砌长句**：一个回答全是长从句，听者累、自己卡，反而低分；
- ❌ **错误复杂**：复杂结构用错，比简单句错误更显眼；
- ❌ **结构单一**：只会用定语从句，其他结构不会；
- ✅ **正确做法**：一个回答中，简单句为主干，复杂结构做点缀（1–2 个），
  清晰又多样。

## 五、目标

- 4 周内：每次回答能自然使用 1–2 个复杂结构，且正确率高；
- 8 周内：复杂结构运用自动化，无需刻意思考；
- 长期：语法维度稳定在 7.5 档（多样 + 偶有小错不影响理解）。
