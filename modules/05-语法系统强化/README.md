# 模块 5：语法系统强化

## 模块定位

把散见于示范回答中的语法知识系统化，建立"**结构清单 + 错误自查 + 多样性训练**"
三位一体的语法能力，支撑 7.5 语法维度（多种复杂结构、偶有错误但不影响理解）。

## 为什么需要这个模块

- 语法维度是 6.5 → 7.5 的硬门槛：7.5 要求"能使用多种复杂结构"；
- 中国学习者的通病：简单句为主、复杂结构少、时态混乱；
- 本模块不追求语法理论深度，只练**考试与口语中真正用得上的结构**。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `01-高频语法结构清单.md` | 考试口语高频结构：条件句、从句、被动、完成时、比较等，讲透+例句 |
| `02-常见错误自查表.md` | 高频语法错误的自查清单，录音/写作后逐项检查 |
| `03-语法多样性训练.md` | 刻意练习方法，让复杂结构自然融入表达 |

## 使用建议

- **每周 2–3 次**，每次 15–20 分钟：学一个结构 → 造句 → 在回答中使用；
- 按清单顺序推进，每个结构做到"会用"再下一个；
- 每次录音后用自查表过一遍，统计错误类型；
- 与模块 03（词块）配合：词块 + 复杂结构 = 语法多样性的双重保障。
