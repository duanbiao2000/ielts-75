# 高频语法结构清单

> 目标：掌握雅思口语真正高频的复杂结构，每个结构做到"会认、会用、自然用"。
> 用法：逐个学习，用例句仿写，再放进自己的回答。

## 一、条件句（Conditionals）

**第一类（真实可能）**：If + 一般现在时, … will + 动词原形
- 例句：If I get the chance, I will travel to Europe.
- 用途：谈计划、预测（Part 3 高频）

**第二类（假设/建议）**：If + 过去式, … would + 动词原形
- 例句：If I had more time, I would learn a musical instrument.
- 用途：谈假设、愿望、委婉建议

**混合型**：If + 过去完成时, … would + have + 过去分词
- 例句：If I had prepared more, I would have done better.
- 用途：事后反思（谈经历类话题卡）

## 二、各类从句（Clauses）

**定语从句（相对代词）**：…, which/who/that …
- 例句：I'm studying computer science, which focuses on programming.
- 用途：给名词加细节，展示语法多样性（极高频）

**原因从句**：because / since / as
- 例句：I chose this major because I've always been fascinated by technology.

**时间从句**：when / while / as soon as
- 例句：Whenever I feel stressed, I go for a run.

**条件从句**：if / as long as / unless
- 例句：As long as you keep practising, you'll improve.

**让步从句**：although / even though / while
- 例句：Although the course is challenging, I enjoy it.

## 三、被动语态（Passive）

- 结构：be + 过去分词
- 例句：More and more people are said to be working from home.
- 用途：客观讨论现象、强调动作对象（Part 3 学术感表达）

## 四、完成时（Perfect Tenses）

**现在完成时**：强调与现在的关联
- 例句：I've been learning English for ten years.
- 用途：谈经历、持续状态（经历类话题卡高频）

**过去完成时**：过去某时之前已完成
- 例句：By the time I arrived, the meeting had already started.
- 用途：叙述过去经历中的先后顺序

## 五、比较结构（Comparisons）

**比较级**：… is more … than …
- 例句：I find reading more relaxing than watching TV.

**倍数/程度**：… is twice as … as …
- 例句：The new building is twice as tall as the old one.

**the + 比较级…, the + 比较级…**
- 例句：The more you practise, the more confident you become.

## 六、虚拟与委婉

**I'd rather / I'd prefer**
- 例句：I'd rather live in a city than in the countryside.

**It's time / It's high time**
- 例句：It's time we took more action on the environment.

**情态动词表推测**：must / might / could / be likely to
- 例句：It could be that the policy will change in the future.

## 七、学习与操练方法

1. **结构识别**：在话题库/场景库的示范回答中，找出每种结构，标注出来；
2. **仿写**：用结构仿照例句写 3 个与自己相关的句子；
3. **植入回答**：在自答问题时，刻意用 1–2 个该结构；
4. **录音验证**：回听确认结构使用正确，形成主动运用习惯。

## 八、优先级

先掌握**定语从句、条件句、完成时**（口语最高频、最容易加分），
再掌握让步从句、比较、被动（进阶丰富表达）。
