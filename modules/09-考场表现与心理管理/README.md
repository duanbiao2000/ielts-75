# 模块 9：考场表现与心理管理

## 模块定位

解决"**会而不秀**"的问题：把学到的语言能力，在考场压力下稳定发挥出来。
涵盖紧张管理、状态调整、考场技巧与身体语言。

## 为什么需要这个模块

- 很多考生平时练得好，考场上因紧张而发挥失常；
- 7.5 不仅考语言，也考"在压力下稳定输出"的心理素质；
- 心理与表现管理是长期项目的最后一块拼图，决定真实水平的兑现率。

## 使用建议

- **考前 1–2 周**集中使用，配合模考模块（模块 04）模拟实战；
- 平时把状态管理融入日常训练，形成习惯；
- 每次模考后复盘"心理与表现"层面：紧张是否影响发挥、技巧是否到位；
- 与场景库「考场应答与考官互动」配合，练就考场全流程的从容。
