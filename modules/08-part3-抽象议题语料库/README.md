# 模块 8：Part 3 抽象议题语料库

## 模块定位

为 Part 3 的抽象、社会性议题提供**系统化的分类语料与示范论证**，
解决"抽象话题没观点、没语料、论证浅"的问题。

## 为什么需要这个模块

- Part 3 是口语上 7.5 的分水岭，抽象议题（社会、科技、教育、环境等）是主战场；
- 抽象话题需要观点 + 论证 + 语料，光有框架不够，还要"有话说"；
- 本模块把常见抽象议题分类，提供**可直接调用的观点、理由、论证句与示范回答**。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `01-抽象议题分类与论证句.md` | 四大类抽象议题：观点句、理由句、论证句，按类组织 |
| `02-高频抽象问题与示范论证.md` | 各议题高频问题 + 完整示范论证（观点-解释-举例-让步） |
| `03-示范变体与反背诵警告.md` | 反背诵警告 + 三种变体策略（直接/个人经验/平衡折中）与对照示范 |

> ⚠️ 重要：所有示范回答均为"学结构、学语料"的样例，**严禁整段背诵**，
> 背诵会被考官识别并降档。详见 03 文件。

## 使用建议

- **每天 15–20 分钟**：学一个议题的语料，用其中 2–3 个表达回答一个相关问题；
- 先掌握 `01` 的论证句（通用弹药），再结合 `02` 的示范完整作答；
- 每个议题**录音回答 2–3 题**，回听检查论证结构与语料运用；
- 与第 5 课（论证框架）、模块 03（词块）配合使用。
