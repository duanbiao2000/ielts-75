# 发音自检清单

> 用途：录音后逐项打分，定位短板，形成"诊断 → 改进 → 验证"的闭环。
> 每项 1–5 分：1=几乎做不到，3=基本做到，5=自然稳定。

## 一、四维度打分表

### 维度 1：音素准确（音标/易错音）
- [ ] 易错音（/θ/ /ð/ /r/ /l/ /v/ /w/ /ʃ/ 等）发音基本准确
- [ ] 长元音与短元音能区分（seat/sit, ship/sheep）
- [ ] 词尾辅音不吞音（复数、第三人称单数等）
- [ ] 多音节词重音位置正确

- [ ] 单词重音位置正确（不把重音放错音节）
- [ ] 句子中实词重读、功能词弱读
- [ ] 有重点强调（把关键信息读得更重）
- [ ] 重音模式不"中式"（不是每个词都一样重）

## 二、常见问题自查（听到以下情况要警惕）

- 读单词像"念拼音"或逐字蹦 → 节奏问题
- 重音位置总错（如 comPAtible 读成 COMpatible）→ 单词重音
- 词尾的 s/z/t/d 吞掉 → 词尾辅音
- 语调平淡、没有起伏 → 语调训练
- 说话时频繁停顿、卡顿 → 多为节奏与信心问题，结合流利度模块

## 三、录音诊断流程（每周一次）

1. **录音**：选一段 1–2 分钟素材（场景库对话或自答 3 个问题）；
2. **打分**：按四维度清单逐项打分，记录每项分数；
3. **对比**：与上一周对比，看是否有进步（关注分数变化，不纠结一次表现）；
4. **定短板**：找出得分最低的 1–2 项，定为本周改进重点；
5. **验证**：下周录音同样素材，检查短板是否改善。

## 四、改进优先级建议

- **先音素，后节奏**：音素不准，节奏与语调无从谈起；
- **先单词重音，后句子重音**：单词重音是基础；
- **先降调升调，后降升调**：基本语调熟练后再练细腻的降升调；
- **先跟读，后自由表达**：模仿到位后，自由表达才会自然。

## 五、记录

把每次诊断的分数与短板写入 `ielts-75/learning-records/`，
形成个人发音进步曲线，冲刺期按短板复习。
