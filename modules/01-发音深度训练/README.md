# 模块 1：发音深度训练

## 模块定位

把第 2 课（连读弱读）、第 9 课（重音语调）从"认知"推进到"**系统训练 + 主动运用**"，
解决发音维度上 6.5 → 7.5 的关键差距：音素准确、重音自然、语调有功能、节奏可控。

## 为什么需要这个模块

- 现有课程只讲了发音的"是什么"，本模块负责"怎么练、怎么自检、怎么改"；
- 发音是 7.5 四个维度中最依赖长期训练的一项，需要每天微练习而非一次性学习；
- 发音问题会反向拖累听力（音素辨听）和流利度（因不敢开口而卡顿）。

## 使用建议

- **每天 15–20 分钟**：音标/易错音微练习 + 跟读 + 自检，长期坚持；
- **顺序**：先过音标与易错音（地基）→ 再练连读弱读与语调（进阶）→ 用自检清单诊断；
- **每周一次**：录一段完整回答，按自检清单打分，记录进步；
- 配合第 2、9 课复习，与场景库对话跟读结合效果最佳。
