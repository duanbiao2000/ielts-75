# 音标与易错音

> 目标：建立 IPA 音标体系，逐个攻克中文母语者的高频易错音。
> 方法：每个音先理解口型/舌位，再跟读练习词，最后在句子中运用。

## 一、IPA 音标体系概览

- **元音（20 个）**：单元音（如 /iː/ /ɪ/ /e/ /æ/ /ɑː/ /ɒ/ /ɔː/ /ʊ/ /uː/ /ʌ/ /ə/ /ɜː/）
  + 双元音（如 /eɪ/ /aɪ/ /ɔɪ/ /əʊ/ /aʊ/ /ɪə/ /eə/ /ʊə/）
- **辅音（28 个）**：爆破音、摩擦音、破擦音、鼻音、边音、半元音等。

**学习要点**：元音决定"饱满度"，辅音决定"清晰度"。元音发得不准，
单词听起来就"不像"；辅音发错，意思可能完全改变（如 ship / sheep）。

## 二、中文母语者高频易错音

### 1. /θ/ 和 /ð/（th 音）
- **问题**：容易用 /s/ /z/ 或 /f/ /d/ 替代（如 think → sink）。
- **要领**：舌尖伸出，放在上下齿之间，送气。
- **练习词**：think, three, thank, bath, weather, together, mother, father

### 2. /r/ 和 /l/
- **问题**：/r/ 发成 /l/，或 /l/ 发成 /r/；词尾 /l/ 常丢失。
- **要领**：/r/ 舌尖卷起、不碰口腔任何部位；/l/ 舌尖抵上齿龈。
- **练习词**：right/light, red/led, road/load, green/gleen
- **词尾练习**：call, tell, small, full, ball

### 3. /v/ 和 /w/
- **问题**：/v/ 发成 /w/（very → wery）。
- **要领**：/v/ 上齿咬下唇振动声带；/w/ 双唇收圆，不碰牙齿。
- **练习词**：very, visit, vest, wine, wet, away

### 4. /ʃ/ /tʃ/ /dʒ/（sh / ch / j 组）
- **问题**：/ʃ/ 发成 /s/；/tʃ/ /dʒ/ 发成 /t/ /d/。
- **要领**：/ʃ/ 双唇微收，舌面靠近硬腭；/tʃ/ 是 /t/+/ʃ/ 的合音。
- **练习词**：sheep, ship, fish, chair, chat, job, joke, jeep

### 5. 短元音 /ɪ/ 与 /iː/、/æ/ 与 /e/
- **问题**：长元音与短元音不分（seat/sit, beat/bit）；/æ/ 与 /e/ 混淆。
- **要领**：/iː/ 拉长、放松；/ɪ/ 短促、口腔更松；/æ/ 嘴巴张大，/e/ 嘴巴稍收。
- **练习词**：seat/sit, beat/bit, ship/sheep, bad/bed, man/men

### 6. 词尾辅音
- **问题**：词尾 /s/ /z/ /t/ /d/ /k/ 吞音。
- **要领**：词尾辅音要"发完"，尤其 /s/ /z/（复数、第三人称单数）。
- **练习词**：books, cats, dogs, students, plays, walks

## 三、练习方法

1. **单音跟读**：听标准发音 → 模仿 → 录音对比，每个音 3 遍；
2. **最小对立组**：用对比词练（seat/sit、ship/sheep），听出差异再模仿；
3. **词表朗读**：把易错音词表每日朗读一遍，录音回听，标记还错的音；
4. **句子运用**：在场景库对话中找含该音的句子，整句跟读，体会自然运用。

## 四、自测

- 朗读易错音词表，录音后对照标准发音，统计正确率；
- 让（或请 agent）听录音，标记仍不准确的音；
- 目标：两周内易错音正确率从 60% → 90%。
