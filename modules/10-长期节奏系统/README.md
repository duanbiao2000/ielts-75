# 模块 10：长期节奏系统

## 模块定位

为整个长期项目提供**阶段路线、复习循环与晋级标准**，
把零散的训练整合成可持续、有节奏、可验证的系统。

## 为什么需要这个模块

- 口语提升是长期过程，没有节奏就会"练一阵、荒一阵"，效果打折；
- teach 体系本身不安排复习与退出标准，需要外部系统补上；
- 本模块是"总调度"：规划阶段、安排复习、定义达标，让长期坚持有章可循。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `01-阶段路线图.md` | 基础期 → 强化期 → 冲刺期 → 维持期的阶段目标与任务 |
| `02-复习循环与晋级标准.md` | 间隔复习机制、阶段验收、晋级标准、长期维持策略 |

## 使用建议

- **先读路线图**，明确当前处于哪个阶段、该做什么；
- **按阶段推进**：完成一个阶段的验收，再进入下一阶段；
- **复习循环贯穿全程**：用间隔复习对抗遗忘，用模考验证阶段成果；
- 与所有模块、话题库、场景库配合，形成完整系统。
