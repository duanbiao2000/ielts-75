# 复习循环与晋级标准

> 目标：建立"间隔复习 + 阶段验收 + 晋级标准"的长期机制，
> 对抗遗忘、验证进步、定义达标，让长期坚持可持续。

## 一、间隔复习机制（对抗遗忘的核心）

口语能力会遗忘，必须用间隔复习维持。机制如下：

### 复习内容
- **词块与同义替换**（模块 03）：Anki 每日复习；
- **话题语料与场景表达**：按"学过后第 1 天、第 3 天、第 7 天、第 14 天"回顾；
- **易错音与发音要点**（模块 01）：每周回顾一次易错音词表；
- **语法结构与错误自查**（模块 05）：每周回顾一次自查表；
- **模考短板**：按复盘日志的短板清单，每两周验证一次。

### 复习方式
- **Anki 为主**：词汇、词块、同义替换、易错音，全部进卡片，每日复习；
- **录音回顾**：每周回听一次自己的录音（一个月前的），对比进步；
- **快速自测**：看到话题卡，快速说一遍要点（不录音，练反应）；
- **场景复用**：随机挑一个场景，用其表达回答一个问题，保持熟练。

### 复习纪律
- **每日 10–15 分钟**固定复习时间，形成习惯；
- **不积压**：复习内容每天清零，不累积成负担；
- **以"会用"为准**：复习不是"认识"，是"能说出来、用得对"。

## 二、阶段验收

每个阶段结束，用以下方式验收（对应路线图的验收标准）：

| 验收项 | 方式 | 工具 |
| --- | --- | --- |
| 发音 | 录音 + 自检清单打分 | 模块 01 清单 |
| 流利度 | 录音统计填充词、反应时间 | 模块 02 计划 |
| 词汇 | 回答中词块/替换的运用 | 模块 04 自评 |
| 语法 | 录音错误自查 | 模块 05 自查表 |
| 综合 | 完整模考 | 模块 04 模考流程 |

**验收原则**：量化、客观、以模考分数为准，不凭感觉。

## 三、晋级标准

### 阶段晋级
- **基础期 → 强化期**：易错音正确率 ≥ 70%；填充词 ≤ 3 次/分钟；
  框架句自动化、回答稳定 3–4 句；
- **强化期 → 冲刺期**：模考综合 ≥ 7.0；Part 2 稳定讲满、结构完整；
  Part 3 论证完整；各维度短板已定位纠正；
- **冲刺期 → 达标**：连续两次模考，听力 32–34/40，
  口语各维度达 7.5 档描述，考场状态稳定。

### 最终达标（退出标准）
- 连续两次模考达标（见上）；
- 且考场表现稳定，无发挥失常；
- 达标后进入维持期，防止回退。

### 未达标的处理
- **不推进新内容**：回到短板专项，纠正后再模考验证；
- **分析原因**：是训练量不足、方法不对、还是心态问题，针对性调整；
- **延长阶段**：允许延长当前阶段，以"达标"为准，不以时间为准。

## 四、长期维持策略（达标后）

1. **持续输入**：保持模块 06 的听力输入与跟读，维持语感；
2. **间隔复习**：维持 Anki 复习，防止词汇与表达回退；
3. **真实运用**：在留学/工作/社交中主动使用口语，把能力变成习惯；
4. **定期监控**：每月一次模考或完整自测，发现回退及时补强；
5. **设定新目标**：如追求更高分数、更地道表达，进入新一轮"强化→冲刺"。

## 五、长期项目心态

- **接受波动**：进步不是直线，会有平台期，坚持即可突破；
- **关注趋势**：看长期分数曲线，不纠结单次模考波动；
- **小步快跑**：每天 1–2 小时稳定投入，胜过突击；
- **记录即成长**：学习档案（分数追踪 + 复盘日志）是长期坚持的见证。
