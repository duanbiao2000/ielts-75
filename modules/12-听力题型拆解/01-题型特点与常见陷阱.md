# 题型特点与常见陷阱

> 目标：掌握 7 大题型的出题逻辑与陷阱，每种题型知道"坑在哪、怎么避"。
> 原则：**先判断题型 → 预读题目 → 带着预测去听 → 识别陷阱**。

## 一、表格/笔记/表格填空题（Form / Note / Table completion）

**出题逻辑**：填写具体信息（姓名、地址、数字、日期、名词）。

**常见陷阱**
- **字数限制**：ONE WORD AND/OR A NUMBER 等限制，多写即错；
- **拼写与大小写**：人名、地名需正确拼写；
- **单复数**：名词的可数性；
- **原文原词陷阱**：答案常是原文原词，但**顺序可能被重组**，
  不要听到类似词就急着写。

**应对策略**
- 预读时判断**词性与词义范围**（填数字还是名词？什么主题的词？）；
- 听到答案先在题目上速记，誊写时再完整拼写；
- 注意题目的字数要求，逐题核对。

## 二、选择题（Multiple choice）

**出题逻辑**：选项与音频内容对应，考**同义替换识别**。

**常见陷阱**
- **干扰项**：与音频词汇相近但意思不符的选项（形似陷阱）；
- **顺序陷阱**：选项顺序与音频出现顺序不一致；
- **"先提到的不选"**：部分题目中，先出现的表述常是干扰；
- **转折后出答案**：but / however / actually 之后常出正确选项。

**应对策略**
- 预读选项时**概括每项的核心意思**，而非记单词；
- 听"意思"而非"原词"：正确选项通常是音频内容的同义转述；
- 注意转折与强调信号词，答案常在其后。

## 三、配对题（Matching）

**出题逻辑**：把题干与选项配对，选项可能**使用一次、多次或不使用**。

**常见陷阱**
- **顺序错位**：选项出现顺序与音频不一致；
- **同义替换密集**：选项与音频大量同义转述，靠原词匹配必错；
- **干扰选项**：部分选项与音频内容无关，用于混淆。

**应对策略**
- 预读时为每个选项**预测同义替换**（它可能被怎么改写）；
- 听"意义匹配"，边听边在选项旁打钩，听完再配对；
- 注意"排除法"：确定一个错配，缩小其他选项范围。

## 四、句子/摘要填空题（Sentence / Summary completion）

**出题逻辑**：补全句子或摘要，答案在音频中以同义转述出现。

**常见陷阱**
- **字数限制**：通常 ONE WORD OR TWO WORDS；
- **语法提示**：空格前后的词性提示（冠词后填名词等）；
- **摘要题信息密集**：一段摘要对应大量信息，容易漏听。

**应对策略**
- 读句子时**预判空格的词性与含义**，带着预测去听；
- 摘要题先抓每句的核心，再定位答案；
- 答案常是**原文原词或同义替换**，两者都要能识别。

## 五、地图题（Map labelling）

**出题逻辑**：在地图上标注地点，考**方位与方向**。

**常见陷阱**
- **方位词密集**：left / right / opposite / behind / next to / in the corner；
- **参照物变化**：以不同地标为参照，描述路径易混；
- **语速快、信息集中**：一段音频覆盖多个标注，漏一个难补。

**应对策略**
- 预读时**在地图上标出已知地标与方位**，建立空间框架；
- 边听边在图上画箭头/标记，不要只靠脑子记；
- 重点听方位词与参照物（near… / on the opposite side of…）。

## 六、图片标注题（Picture labelling）

**出题逻辑**：在图片上标注各部分名称，考**描述与定位**。

**常见陷阱**
- **描述性语言**：答案靠描述定位（the object on the left），非直白名称；
- **图片细节多**：预读时要看清各部分，否则听不懂对应关系。

**应对策略**
- 预读时**为图片各部分预测词汇**（这是什么？可能怎么描述？）；
- 听描述时同步在图上定位，确认指向。

## 七、简答题（Short-answer）

**出题逻辑**：用简短答案回答 wh-问题（when / where / what）。

**常见陷阱**
- **答案简短但要求精确**：时间、地点、数字；
- **单复数与形式**：回答需符合问题形式。

**应对策略**
- 预读问题，判断**答案类型**（时间？地点？事物？）；
- 听到对应信息立即速记，注意问题所问的精确内容。

## 八、通用原则（所有题型）

1. **预读永远优先**：利用读题时间建立预测，带方向去听；
2. **听意思，不听原词**：同义替换是雅思听力的底层逻辑；
3. **答案速记，誊写核对**：先在题目上缩写，最后 10 分钟誊写时
   补全拼写、单复数、大小写；
4. **错过不恋战**：某题没听清，立即转向下一题，避免连环失分。
