# 模块 12：听力题型拆解

## 模块定位

在 11 课的听力策略课（0006–0008）之上，提供**按题型拆解的应试层**：
每种题型的出题逻辑、常见陷阱与应对策略，配合时间分配与预测技巧，
把"听力 7.5"落到每一道题的准确率上。

## 为什么需要这个模块

- 听力提分的关键不是泛听量，而是**题型陷阱的熟悉度**；
- 不同题型陷阱完全不同：选择题考干扰项识别，地图题考方位词，
  填空题考拼写与字数限制，通用策略无法覆盖；
- 7.5 意味着 32–34/40，每类题型的失分点都要精准封堵。

## 使用建议

- **学完第 6–8 课之后**使用本模块，把通用策略落到题型细节；
- 每周模考后，按本模块核对失分题型，做针对性纠错；
- 与模块 06（输入）配合：精听素材练能力，本模块练应试；
- 与模块 04（模考）配合：用模考分数验证题型拆解的效果。
