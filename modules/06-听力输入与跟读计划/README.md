# 模块 6：听力输入与跟读计划

## 模块定位

为口语提供**长期、稳定、分级的输入**：精听、泛听、影子跟读、多口音适应。
口语输出的上限，由输入的质量与持续性决定。

## 为什么需要这个模块

- 口语的词汇、语感、语音、语调，都来自**长期输入**，无法速成；
- 只练输出不练输入，表达会"没货"、语音会"没参照"；
- 雅思听力与口语共享语音与词汇基础，本模块同时反哺听力（提分双赢）。

## 使用建议

- **每天 20–30 分钟**：精听/泛听 + 跟读，作为长期习惯；
- 精听重质量（三遍法），泛听重数量（磨耳朵）；
- 跟读与发音模块（模块 01）配合，输入即输出训练；
- 素材从易到难：真题 → BBC 6 Minute English → TED → 学术讲座。
