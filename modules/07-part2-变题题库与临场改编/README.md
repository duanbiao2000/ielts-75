# 模块 7：Part 2 变题题库与临场改编

## 模块定位

在话题库 Part 2 素材（第 4、10 课的结构与一材多用）基础上，
提供**更系统的故事模板、题库归类策略与临场改编训练**，
应对题库中成百上千的话题卡。

## 为什么需要这个模块

- Part 2 题库话题数量庞大，逐个准备不现实；
- 高效策略是"**有限素材 × 归类策略 × 临场改编**"；
- 很多考生有素材，但临场改编能力弱，导致"有故事讲不出、讲不贴题"；
- 本模块专门训练"把素材快速贴合任何题目"的能力。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `01-故事模板库.md` | 5 类核心故事模板，可覆盖绝大多数话题卡 |
| `02-题库归类策略.md` | 把海量话题卡归类到有限素材的系统方法 |
| `03-临场改编练习.md` | 一材多用的改编训练，练"快速贴合题目"的能力 |

## 使用建议

- **先学归类策略**（02），理解"一材多用"的底层逻辑；
- 再准备 5 个故事（01），每个故事按模板打磨；
- 每天做 1–2 组**临场改编练习**（03），练速度与贴合度；
- 用模考模块（模块 04）验证：随机抽题，限时准备 + 讲述。

## 与现有资源的关联

- 素材：话题库 16 个文件夹的 Part 2 素材；
- 验证：模块 4 模考中的 Part 2 表现。
