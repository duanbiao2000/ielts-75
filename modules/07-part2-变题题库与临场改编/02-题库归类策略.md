# 题库归类策略

> 目标：掌握把海量话题卡**快速归类**到有限素材的系统方法，
> 做到"看到任何话题卡，30 秒内找到可用素材"。

## 一、核心思路：题目 = 素材 × 角度

任何话题卡，本质上都是在问：**用哪个素材，从哪个角度切入**。

- **素材**：你的 5 个核心故事（见 01）；
- **角度**：题目要求的侧重点（人物、经历、地点、物品、感受等）。

归类公式：**先看题目问什么，再找对应素材，调整切入角度。**

## 二、归类速查表

### 人物类（a person…）→ 素材 2（你影响深的人）
- a person you admire / who influenced you / a friend / family member / teacher
- **切入角度**：调整"最突出的品质 + 具体事件 + 影响"

### 经历类（a time / experience…）→ 素材 1（成长经历）
- a challenge / something you did for the first time / an unforgettable experience /
  a decision
- **切入角度**：调整"困难 → 应对 → 收获"

### 地点类（a place…）→ 素材 3（旅行/地点）
- a place you visited / want to visit / a city / a quiet place
- **切入角度**：调整"位置/场景 + 具体经历 + 感受"

### 物品类（an object…）→ 素材 4（物品/技能）
- a gift / an object you use / a skill / a hobby
- **切入角度**：调整"怎么来的 + 过程 + 意义"

### 社会/社区类 → 素材 5（社区经历）
- a voluntary activity / community event / neighbour / help
- **切入角度**：调整"活动 + 过程 + 感受"

### 综合类 → 灵活组合
- a goal you achieved → 素材 1（经历）+ 素材 4（技能）
- a change that improved your life → 素材 1（经历）或素材 3（旅行）
- a success you're proud of → 素材 1（经历）

## 三、归类三步法（临场操作）

1. **判类型**：题目是人物、经历、地点、物品、社会还是综合？
2. **选素材**：按上表找到对应的核心故事；
3. **调角度**：按题目的具体要求，调整开场句与重点（见 03）。

**训练目标**：30 秒内完成"判类型 → 选素材 → 定角度"。

## 四、常见陷阱与应对

**陷阱 1：为套素材而偏离题目**
- 应对：先对齐题目要求，再套素材；改编时检查"开场是否回应了题目"。

**陷阱 2：一个故事硬套所有题**
- 应对：同一故事不同题目，开场与重点必须不同，否则考官听出"背稿"。

**陷阱 3：细节太泛，讲不满 2 分钟**
- 应对：准备时按"时间/地点/人物/事件/感受"五要素列关键词，
  细节具体才能讲满。

**陷阱 4：准备时间浪费在写句子**
- 应对：只写关键词，讲的时候现场扩展（填充公式）。

## 五、归类训练

- 用话题库的 Part 2 话题卡，每天做 3–5 张的归类练习：
  限时 30 秒，说出"用哪个素材、从哪个角度切入、开场怎么改"；
- 录音验证：按归类结果准备并讲述，检查是否贴合题目；
- 统计：哪些类型最容易归类、哪些最容易偏离，针对性强化。
