# 故事模板库

> 目标：准备 5 个核心故事，覆盖绝大多数 Part 2 话题卡。
> 每个故事按统一模板打磨：**背景 → 过程 → 细节 → 感受**。

## 模板结构（所有故事通用）

1. **开场**：一句话点题，直接进入；
2. **背景**：时间、人物、地点、场景（四要素）；
3. **过程**：发生了什么，含 1–2 个具体细节；
4. **感受/意义**：为什么难忘、带来什么影响。

## 故事模板 1：一个让你成长的经历（覆盖：经历、挑战、第一次）

**适用话题**：a challenge you overcame / something you did for the first time /
an unforgettable experience / a decision you made

**要点**：
- 背景：什么时间、什么处境、遇到了什么困难；
- 过程：如何应对（行动细节）、谁帮助了你；
- 结果：结果如何、你学到了什么；
- 感受：对性格或观念的影响。

**示例**：第一次独立完成一个项目——从紧张到通过准备克服困难，
学会了"准备是自信的来源"。

## 故事模板 2：一个对你影响深的人（覆盖：人物类所有话题卡）

**适用话题**：a person you admire / who influenced you / a friend /
a family member / a teacher

**要点**：
- 人物：是谁、什么身份、最突出的品质（1–2 个）；
- 事件：一个具体场景（他/她做了什么、说了什么）；
- 影响：对你性格、选择、价值观的改变；
- 收尾：他/她的话或行为至今仍影响你。

**示例**：爷爷/老师用行动教会你坚持与诚实，这句话至今影响你。

## 故事模板 3：一次旅行/到一个想去的地方（覆盖：地点、旅行类）

**适用话题**：a trip you enjoyed / a place you visited / a place you want to visit /
a journey

**要点**：
- 背景：什么时候、和谁、去哪里、为什么去；
- 过程：做了什么、有什么具体经历（1–2 个细节）；
- 感受：最难忘的瞬间、为什么难忘、带来的改变。

**示例**：一次山间小镇的旅行——景色、慢节奏、与朋友的经历，
让你明白"慢下来"的意义。

## 故事模板 4：一个喜欢的物品或学会的技能（覆盖：物品、技能类）

**适用话题**：a gift / an object you use / a skill you learned / a hobby

**要点**：
- 是什么：物品/技能，怎么来的或怎么开始的；
- 过程：怎么使用/学习、遇到什么困难、如何克服；
- 意义：为什么珍视/喜欢、带来什么。

**示例**：一台相机/一个爱好——从零开始学习，通过坚持获得成就感，
也教会你耐心。

## 故事模板 5：一个社会/社区相关经历（覆盖：社会、社区、帮助类）

**适用话题**：a voluntary activity / a community event / a neighbour who helped you /
something you did for others

**要点**：
- 背景：什么活动、什么时候、为什么参与；
- 过程：做了什么、有什么互动细节；
- 感受：感受到什么、带来的影响（社区精神、归属感）。

**示例**：一次社区志愿活动——人们的参与和感谢，让你体会到集体行动的力量。

## 使用纪律

1. **5 个故事即可覆盖大部分题目**，不要贪多，重在打磨；
2. **每个故事按模板写提纲**（关键词，不写整句）；
3. **一材多用**：同一个故事，按题目调整开场与重点（见 03）；
4. **录音验证**：每个故事限时讲 2 分钟，回听检查是否讲满、贴合。
