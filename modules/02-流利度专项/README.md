# 模块 2：流利度专项

## 模块定位

流利度是口语 7.5 的"生命线"，也是目前体系中训练最薄弱的一环。
本模块把流利度拆成**可训练的子技能**，做专项突破。

## 为什么需要这个模块

- 流利度不是"说得多快"，而是**连贯、少无意义停顿、节奏自然**；
- 大量 6.5 考生的卡点不在词汇语法，而在"说到一半断掉、反复自我纠正、
  用填充词填充空白"；
- 流利度可以通过**刻意训练**显著提升，是投入产出比最高的专项。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `01-填充词与自我纠控制.md` | 识别并替换 um/er/like 等填充词，控制过度自我纠正 |
| `02-快速组织与限时反应.md` | 听题后快速搭建回答框架，模拟考场即兴反应 |
| `03-流利度训练计划.md` | 分阶段训练安排、每日练习清单、进步追踪 |

## 使用建议

- **每天 20–30 分钟**：填充词训练 + 限时反应训练，长期坚持；
- 先做 `01` 的"识别与替换"，再做 `02` 的"快速组织"，最后按 `03` 的计划推进；
- 所有训练都要**录音回听**，量化停顿次数与填充词次数；
- 与发音模块、模考模块配合：发音改善会减少卡顿，模考验证综合效果。
