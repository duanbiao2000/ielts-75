# 模块 11：考官视角与分数校准

## 模块定位

以**雅思考官的视角**补上资料库的"评分可信度"层：
提供分数参照锚（校准库）、考官评分习惯批注、以及追问压力训练，
解决"自评高估""示范模板化""缺少追问应对"三大落地漏洞。

## 为什么需要这个模块

- 自评容易高估：没有真实分数参照，四维度自评表的可信度打折；
- 示范易被背稿：固定句式的示范被逐字背诵，考官能识别并降档；
- 追问压力缺失：真实考试中考官会追问、打断，只练标准流程不够；
- 本模块把"考官在听什么、什么会扣分"显性化，让训练对准真实评分。

## 使用建议

- **每次模考前/后**：用校准库（01）校准自己的自评分数，避免高估；
- **学习新话题/模块时**：对照批注（02）理解考官视角，调整表达策略；
- **每周 1 次**：用追问题库（03）做追问压力训练，录音回听；
- 与模块 04（自评表）、模块 08（Part 3 示范）、模块 09（考场心态）联动。

## 与现有资源的关联

- 批注与追问题库衔接场景库「考场应答与考官互动」及模块 09；
- 反背稿警告回填至话题库各 Part 3 文件与模块 08 示范变体。
