## 已知限制 / 发布须知

1. **录音在无麦克风环境仅降级提示**，不阻断文字演练；iOS Safari 偏好 `audio/mp4`，已按探测序列选择 mimeType。
2. **SW 缓存版本手动 bump**：发布后修改任何静态资源，必须将 `sw.js` 的 `CACHE` 提升到下一版本号，否则客户端沿用旧缓存。本次 v1.0 为 `ielts75-v2`（相对 T-5.4 交付的 v1，app.js 有修复）。
3. **真机测试**：自动化覆盖了三引擎 + 设备视口模拟；建议发布后补充 1 台 iPhone Safari 真机走查录音与键盘弹出遮挡场景。
4. **SW 仅在 http(s) 生效**：双击 index.html（file://）无离线能力；经任意静态服务器访问即可。预览 iframe 下静默跳过注册。
5. **学习记录**存于浏览器 localStorage（单键 + learning-records 流水）；跨设备同步需依赖 T-5.1 导出/导入备份（导出已实现，导入属后续版本）。
6. 游戏化奖励与学习目标对齐（C-7）：XP 仅来源于学习行为，无数值膨胀机制。
