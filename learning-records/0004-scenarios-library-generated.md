# Learning Record 0004 — 场景库生成完成（2026-11-20）

## 背景

学习者希望在话题素材库之外，增加更多**可直接采纳学习的场景**，
覆盖考试、生活、职场、出行、留学、旅行、社交七大领域。
按规划生成 **24 个场景**，每个 3 个文件，共 72 个文件。

## 场景库结构（`ielts-75/materials/scenarios/`）

- **考试（2）**：考场应答与考官互动、考前考后交流与情绪表达
- **生活（5）**：租房与居住沟通、购物与退换、餐饮与点餐、医疗与就诊、银行与电话客服
- **职场（4）**：面试与自我介绍、入职与日常沟通、会议与汇报、请假加班与离职沟通
- **出行（4）**：机场与航班、酒店入住与退房、交通与问路、旅行突发情况
- **留学（4）**：申请与入学注册、课堂与学术沟通、校园生活服务、留学适应与跨文化沟通
- **旅行（2）**：行程规划与预订、旅行中的社交与体验
- **社交（3）**：日常寒暄与介绍、聚会邀请与回应、情绪与关系表达

每个场景固定 3 个文件：README（定位与重点）、核心表达（词+句型+易错）、
情景对话与练习（2 段对话+自测任务）。另附 `00-使用指南.md`。

## 设计要点

- 表达对齐雅思 7.5：自然、地道、有变化，不堆生僻词；
- 对话标注【】可替换表达，供学习者形成自己版本；
- 所有场景均标注与 11 课方法论及 16 个话题文件夹的迁移关系。

## 使用约定

- 场景库（表达）+ 话题库（话题与结构）联动使用；
- 每个场景必须开口录音或角色扮演，只读不练无效；
- 卡点继续记录到 learning-records，冲刺期按记录复习。
