# 主管反馈模板

> 用途：统一主管（口语教练）反馈口径，让反馈**有证据、有动作、可执行**。
> 原则：先给证据（具体表现），再给动作（指向模块），最后给鼓励。
> 评分口径与模块 11「分数校准库」对齐，避免"感觉不错"式反馈。

## 一、反馈基本原则

1. **证据优先**：引用录音中的具体句子或现象，不评抽象感觉；
2. **动作落地**：每条反馈对应一个具体训练动作（指向模块/任务卡）；
3. **一次聚焦**：每次反馈聚焦 1–2 个最大短板，不面面俱到；
4. **先肯定后改进**：先指出做得好的（也要给证据），再给改进点；
5. **不制造挫败**：改进动作是"下次怎么练"，不是"你不行"。

## 二、5 分钟反馈流程（模考反馈用）

1. **（1 分钟）总评**：综合档位 + 一句话整体印象（证据支撑）；
2. **（2 分钟）四维度反馈**：按模板逐维度给分 + 证据；
3. **（1 分钟）改进动作**：1–2 条，指向具体模块/任务卡；
4. **（1 分钟）确认与鼓励**：员工复述改进动作，确认理解，给予鼓励。

## 三、四维度反馈模板（填空即用）

### 流利度与连贯（得分：__/9）
- **证据**：本次回答中，[具体表现，如"Part 3 能连续表达 5–6 句，衔接自然" / "填充词每分钟约 X 次，Part 1 有两处长停顿"]；
- **动作**：[如"跟练模块 02 填充词控制，每日任务卡 D5 的统计练习连续做一周" / "用模块 02 快速组织法重练该题"]；

### 词汇（得分：__/9）
- **证据**：[如"使用了 double-edged sword、hands-on 等地道搭配，转述自然" / "important 重复 X 次，搭配偏基础"]；
- **动作**：[如"把模块 03 同义替换表中的 X 组词块进 Anki，本周任务卡每日用 2 个造句" / "继续积累模块 03 功能词块"]；

### 语法（得分：__/9）
- **证据**：[如"简单句与从句混合使用，时态正确" / "Part 3 复杂结构使用少，X 处主谓一致错误"]；
- **动作**：[如"按模块 05 高频结构清单练 X 结构，重答该题" / "对照模块 05 常见错误自查表逐条排查"]；

### 发音（得分：__/9）
- **证据**：[如"整体清晰可懂，意群停顿自然" / "易错音 X 处仍偏差，语调偏平"]；
- **动作**：[如"按模块 01 易错音词表每日跟读，模块 01·04 意群练习" / "跟读模块 06 素材并录音对比"]；

## 四、常见问题反馈话术

### 1. 有背诵痕迹（高危，优先处理）
- **证据**："Part 2 与 Part 3 的开场句式完全相同，且没有个人细节，考官会判定背诵"；
- **动作**："按模块 08·03 示范变体，把该回答改写成个人经验版；话题卡只写关键词，现场扩展。重答并录音"；
- **提醒**："背诵是流利度降档的直接原因，我们练的是素材与思路，不是背稿"。

### 2. 填充词过多 / 长停顿
- **证据**："本次回答中 um/er 出现约 X 次，最长停顿约 X 秒，出现在 X 处"；
- **动作**："模块 02·01 填充词自查表，每天晨会开口时刻意控制；重答该题，目标每分钟 ≤ 3 次"；

### 3. 语域串味（Part 1 太正式 / Part 3 太随意）
- **证据**："Part 1 的回答用了书面腔（如 furthermore），Part 3 只给了一句观点没有展开"；
- **动作**："按模块 03·04 语域转换训练，做该题的双向改写各一遍，录音对比"；

### 4. 论证结构缺失（Part 3）
- **证据**："该题只有观点，没有解释和举例，让步也没有"；
- **动作**："按模块 08 的'观点—解释—举例—让步'框架重答，参考模块 08·02 示范的结构（不背内容）"；

### 5. 追问时慌乱
- **证据**："被追问时先沉默了约 X 秒，然后重复了已说内容"；
- **动作**："用模块 11·03 追问题库，每天 1 组自问自答，练'先响应再展开'"；

### 6. 发音可懂度问题
- **证据**："整体可懂，但意群切分不自然，重音模式偏平，'逐词蹦'感明显"；
- **动作**："模块 01·04 意群与重音训练，每天朗读前先画意群线，录音自检可懂度"；
