# 推广配套练习材料 · 使用指南

> 定位：与《员工口语强化应用推广方案》（`employee-rollout-plan.md`）配套的
> **拿来即用的练习材料包**。员工无需自行寻找素材——每天练什么、怎么练、
> 交什么凭证，全部在本材料包中固定下来。

## 一、材料包结构

| 文件 | 用途 | 使用者 |
| --- | --- | --- |
| `01-每日微练任务卡（4周）.md` | 28 天固定任务：晨会开口 / 午间跟读 / 晚间录音，逐日指定 | 员工 |
| `02-场景角色扮演练习包.md` | 30 个场景的角色扮演卡：角色、任务、成功标准，开练即用 | 员工（结对） |
| `03-每周模考执行单.md` | 全真模考完整流程单：题目流程、计时、答题卡、自评、反馈区 | 员工 + 主管 |
| `04-练习记录与打卡表.md` | 每日打卡、模考分数记录、90 天曲线、凭证提交清单 | 员工 + 主管 |
| `05-主管反馈模板.md` | 四维度反馈模板与常见问题话术，统一反馈口径 | 主管 |

## 二、与 90 天排期的对应

| 推广阶段 | 使用材料 |
| --- | --- |
| 启动期（第 1 周） | 第 1 课诊断 + `04-练习记录与打卡表.md` 建立基线 |
| 筑基期（第 2–4 周） | `01-每日微练任务卡` 第 1–3 周 + `02-场景角色扮演练习包` |
| 强化应用期（第 5–8 周） | `01-每日微练任务卡` 第 4 周循环 + `03-每周模考执行单` + 实战任务 |
| 验收激励期（第 9–12 周） | `03-每周模考执行单`（认证用）+ `04-练习记录与打卡表`（数据汇总） |

## 三、使用规则（全员统一）

1. **按卡执行，不自由发挥**：每日任务、角色演练、模考均按本材料包的
   固定流程执行，避免"不知道练什么"和"乱练"；
2. **凭证先行**：所有任务以录音/实战交付为凭证，按
   `日期_姓名_任务` 命名（如 `1120_张三_晚间录音`），提交主管；
3. **任务卡与资料库的关系**：任务卡中的"参考材料"指向资料库既有文件，
   员工只需按任务执行，无需自行检索；
4. **4 周循环进阶**：任务卡为一个标准循环，筑基期用第 1–3 周，
   强化期循环使用并叠加模考；
5. **反馈闭环**：模考后 24 小时内，主管按 `05-主管反馈模板` 给出反馈，
   员工记入打卡表，形成"练—考—评—改"循环。

## 四、最小使用路径（员工视角）

- **每天**：打开 `01-每日微练任务卡` → 完成三段任务 → 录音提交；
- **每周对练**：打开 `02-场景角色扮演练习包` → 与同伴抽卡演练；
- **每周模考**：打开 `03-每周模考执行单` → 按流程完成 → 交主管反馈；
- **每周复盘**：在 `04-练习记录与打卡表` 登记分数与凭证。
